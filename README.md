# ModManager BeamNG

Портативный менеджер модов для [BeamNG.drive](https://www.beamng.com/) на Windows:
показывает установленные моды, включает и выключает их как сама игра, ставит архивы,
следит за обновлениями и ищет моды на сайтах.

Приложение написано на Rust + Tauri 2, интерфейс — SvelteKit 3 и Svelte 5. Старая
версия на C#/WPF лежит в `legacy/` как эталон и в новой сборке не участвует.

- **Гараж** — карточки или плотный список, настоящие названия из `info.json`, копии
  и прошлые версии, галочки для массовых действий, группировка одинаковых модов,
  исправление упаковки архива.
- **Включение и выключение** — как в игре, через `db.json`; при запущенной игре —
  через игровой помощник `bmm_bridge.zip`. Удаление и массовые действия с отменой.
- **Обновления** — проверка при запуске, по расписанию и вручную; состояние каждого
  сайта, повтор после сбоя, проверка одного мода, «Не проверять обновления»,
  пропуск версии, подбор потерянных страниц. «Обновить» открывает страницу мода
  в отдельном окне с этапами и само подхватывает скачанный архив.
- **Поиск** — Modland, STMods и ModsGaming одним запросом; одинаковые моды с разных
  сайтов собираются в одну карточку. Разделы «Машины», «Карты» и «Дополнения»
  листаются без текста (включая Modland), с догрузкой; фильтры и сортировка,
  операторы `автор:`, `тип:`, `сайт:`, подсказки из истории и библиотеки, повтор
  упавшего сайта отдельно.
  Репозиторий BeamNG используется для обновлений, а не для поиска.
- **Установка из архива** — перетащите zip, rar или 7z на окно либо выберите файл
  кнопкой; скачанные архивы подхватываются из «Загрузок» и добавленных папок.
- **Оформление** — тёмная, светлая или системная тема, пять акцентов и градиентные
  пресеты фона, режимы движения «Живо» и «Быстро», живой фон.
- **Обновление самой программы** — проверка GitHub, загрузка с прогрессом, проверка
  размера и SHA-256, безопасный перезапуск и откат.

## Как начать

1. Скачайте `BeamModManager-<версия>.zip` из
   [последнего выпуска](https://github.com/SnikS1337/beamng-mod-manager/releases/latest).
2. Распакуйте в любую папку и запустите `BeamModManager.exe`. Устанавливать ничего
   не нужно; нужен Windows 10/11 и Microsoft Edge WebView2 Runtime — обычно он уже
   есть. Если его нет, программа покажет окно с объяснением и ссылкой на установку:
   без WebView2 окно создать нельзя.
3. Папка модов находится автоматически. Если программа её не нашла — укажите папку
   `mods` или папку пользователя игры в настройках.

Программа не подписана, поэтому SmartScreen может показать предупреждение:
«Подробнее» → «Выполнить в любом случае».

## Состояние

Последний опубликованный выпуск — **1.0.5**. Версии в `Cargo.toml`, `package.json`
и `src-tauri/tauri.conf.json` совпадают с тегом; изменения перечислены в
[CHANGES.md](CHANGES.md).

Если у вас 1.0.4, обновитесь на 1.0.5 **вручную один раз**: эта версия не может
принять обновление из-за старой проверки версии. Скачайте zip с GitHub и замените
exe; начиная с 1.0.5 обновления снова работают автоматически.

На 2026-10-29 проверено: **699 тестов Rust** (2 ignored) и **108 тестов фронтенда**,
`clippy`, `rustfmt`, `svelte-check` и production-сборка проходят.

## Разработка

Нужны Node.js 24, Rust 1.95+ с MSVC x64 и Visual Studio Build Tools 2022.
Подробности, CI и выпуск — в [docs/BUILD.md](docs/BUILD.md).

```bash
npm ci
npm run check
npm test
npm run build
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
npm run tauri dev
```

Структура: `crates/` — Rust-библиотеки (домен, игра, архивы, сайты, проверки,
обновление приложения), `src-tauri/` — окно и IPC, `src/` — SvelteKit-интерфейс,
`fixtures/` — сохранённые страницы сайтов для тестов, `legacy/` — старый C#/WPF.

Документы:
[INFO.md](INFO.md) — подробное описание для пользователя,
[docs/STATUS.md](docs/STATUS.md) — текущее состояние,
[docs/BUILD.md](docs/BUILD.md) — сборка и выпуск,
[docs/DESIGN_MOTION_WEB.md](docs/DESIGN_MOTION_WEB.md) — как устроено движение в текущем интерфейсе.
Остальные файлы в `docs/` — исторические проектные материалы; они помечены сверху.
