# Фикстуры

Сохранённые HTML-страницы сайтов для тестов Rust-адаптеров. Папка на источник:
`modland/`, `modhub/`, `modsgaming/`, `stmods/`, `beamng/` (официальный репозиторий).
`modsfire/` — страницы файлообменника для проверки ссылок и цен, отдельного
адаптера поиска у него нет. `game/` — `db-5mods-0.39.4.json`, `db-5mods-bmw-off-0.39.4.json`,
`db-empty-0.39.4.json` и `startup-0.39.4.ini` настоящей игры 0.39.4 (тесты чтения и
правки `db.json`), `update/` — `latest-0.1.30.json`, образец для тестов самообновления.

- `*-real.html` — настоящие страницы, сохранённые вручную с 2026-10-13. Скрипты, стили и служебные поля (IP,
  CSRF-токены) вырезаны; тест проверяет, что их там нет.
- Остальные (`list-page.html`, `mod-free.html` и др.) — упрощённые образцы, собранные до появления настоящих
  страниц. Их оставляют для старых тестов.

Правила:

- Новую страницу сохраняем целиком, вырезаем только скрипты, стили и служебные поля; дату и источник
  записываем в комментарий к тесту или в этот README.
- Страницы нужны только для тестов парсера: это сохранённые публичные страницы сайтов, программа их только читает.
- Когда сайт меняет вёрстку, добавляем новую версию страницы и обновляем тесты, старую не удаляем.
