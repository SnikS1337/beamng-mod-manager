# Движение и анимации в веб-версии

Дата: 2026-10-21. Стек: Svelte 5 + Tauri 2. Это план для M6; в M2 уже есть только
базовые CSS-переходы карточек и фона.

## Принципы

- CSS-first. Большинство движений — CSS transition/keyframes на `transform` и `opacity`.
- Svelte-переходы — для появления/исчезновения компонентов; `svelte/motion` Spring — только
  для 2–3 «жидких» величин (капля, островок, панель), не для каждой карточки.
- WAAPI — для последовательностей и паузы по таймеру (тост, прогресс, знакомство).
- WebGL — только линза/преломление капли. Панели и карточки остаются CSS: `backdrop-filter`,
  `conic-gradient`-кромка, внутренний блик.
- Анимируются только видимые карточки (12–18 в DOM), только `transform`/`opacity`.
  `getBoundingClientRect` — один раз до/после FLIP, не для 5000.
- `prefers-reduced-motion` и настройки приложения («Анимации», «Фон», «Огоньки») — общий гейт;
  при выключении класс `.motion-off`.
- FPS на виртуалке не критерий. Смотрим длинные задачи, память, DOM и отсутствие блокировки UI.

## Где WebGL

Только линза капли: маленький canvas (≈68×64), SDF скруглённого прямоугольника, выборка фона
со смещением, хроматические каналы 1.0/1.12/1.26, saturation 1.65. Включается при
`liquid && motion > 0.01`; CSS-fallback обязателен. Подписи под каплей на первом этапе не
преломляются — это осознанное упрощение.

## Порядок M6

1. Токены (длительности, кривые, bounce) и стор `motion`; `prefers-reduced-motion` + настройки.
2. CSS: hover/press/выбор, sleep-оверлей, кромка, переключатель; `.motion-off`.
3. `svelte/transition` для тостов, инспектора, плашки, знакомства; View Transitions разделов.
4. FLIP видимой сетки + вход первых 24 + кольцо выбора.
5. Spring-контроллер капли, островка, заголовка, нажатия.
6. Фон/огоньки/искры/бейдж с паузой по видимости и фокусу.
7. WebGL-линза последней, под флагом `liquid`, с CSS-fallback; сравнение на живом экране.

## Сейчас есть

CSS-дрейф пятен, `glass`/`liquid-edge`/`noise`, hover карточки −2 px, простая смена
`filter` при выключении, виртуальная сетка, CSS-переход бегунка Switch. Нет капель, FLIP,
кольца выбора, анимации инспектора, островка, тостов, плашки, знакомства, огоньков, WebGL.

Старый `FramePacer`/`BackgroundPace` не портируем: в WebView нет смысла подгонять фон под
ручной счётчик кадров; достаточно CSS-анимаций и паузы при скрытом окне.
