# Движение и анимации в интерфейсе

Актуально на 2026-10-26. Стек: SvelteKit 3, Svelte 5, Tauri 2 / WebView2.
Документ описывает то, что реализовано в `src/`; исторические проектные материалы
лежат отдельно.

## Режимы

- **Живо** — анимации включены.
- **Быстро** — `html.no-motion`: Svelte-переходы получают `duration: 0`, а CSS-анимации
  и переходы отключаются общим правилом в `src/app.css`. Это глобально, а не только
  для длительностей из токенов: мигание сайтов, полоса проверки, окна и переключатели
  тоже останавливаются.
- **Живой фон** — отдельная настройка, но работает только при включённых анимациях.
- Системный `prefers-reduced-motion` намеренно не переопределяет выбор пользователя.

## Уровни движения

| Что | Технология | Где |
| --- | --- | --- |
| Маршруты, вкладки, фильтры, панель мода, сетка/список | View Transitions API | `src/lib/shell/motion.svelte.ts`, `src/app.css` |
| Появление/исчезновение окон, палитры и тостов | Svelte transitions (`in:`/`out:`, кастомные `css(t,u)`) | `src/lib/shell/transitions.ts` |
| Карточки, состояния, скелеты | CSS keyframes с токенами `--dur-*` | `src/app.css`, компоненты |
| Свет фона | CSS keyframes на `transform`; пауза при скрытом окне | `src/lib/shell/Background.svelte` |
| Переключатели, кнопки, наведение | CSS transitions | `app.css`, компоненты |

## View Transitions

- `motion.run(update, scope)` запускает `document.startViewTransition`, считает
  вложенные переходы и снимает класс scope после завершения.
- Если во время перехода приходит второй клик, старый переход обрывается, а клик
  повторяется по новому DOM — иначе быстрый клик по меню терялся.
- У `ViewTransition.ready` есть `.catch`: при пропуске или ошибке конфигурации
  WebView2 не пишет `Uncaught (in promise)`.
- Имена карточек — 64-битный хеш id (`flowName`), чтобы в больших библиотеках
  не было совпадений `view-transition-name`.
- Гараж: двигаются карточки, сетка и боковая панель; страница не мигает.
- Поиск: фильтр типа использует `flow-search`, карточки переезжают и уходят.
- Настройки и «Обновления»: меняется только содержимое раздела, шапка стоит.

## Svelte transitions

- Палитра: подложка гаснет, панель всплывает с масштабом.
- Окно архива: подложка гаснет, окно появляется из центра; при закрытии — обратно.
- Тосты: появление с подъёмом, исчезновение быстрым фейдом; при замене старого
  тоста новый въезжает, старый гаснет.
- Длительность считается через `motionDuration`: в режиме «Быстро» она равна нулю.
  CSS-правило `prefers-reduced-motion` не действует на Svelte transitions, потому что
  они идут через Web Animations API.

## Производительность и ограничения

- Анимируются только видимые карточки; список и сетка виртуализированы.
- Фон двигается только `transform`; `will-change` снимается в режиме «Быстро».
- При `visibilitychange` в `hidden` фоновый свет ставится на паузу.
- Полоса проверки заполняется до 100% и только потом уступает место кнопкам.
- Исторические `DESIGN_MOTION.md` и `DESIGN.md` описывают старую WPF-версию и не
  являются текущей инструкцией.
