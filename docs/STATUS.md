# Состояние проекта

На 2026-10-30. Основная ветка — `main` (Rust + Tauri). Прежняя C#/WPF-версия
0.3.12 сохранена в ветке `old-main`, её код — ещё и в `legacy/`.

Последний опубликованный выпуск — **1.2.0** (из `main`). Версии в `Cargo.toml`,
`package.json` и `src-tauri/tauri.conf.json` — 1.2.0. Что готовится к следующему выпуску —
раздел «Не выпущено» в [CHANGES.md](../CHANGES.md).

## Стек

- Rust 1.95+, edition 2024, MSVC x64 (`rust-toolchain.toml`);
- Tauri 2.12 (плагины dialog, opener, window-state), WebView2;
- SvelteKit 3.1 (SPA, adapter-static), Svelte 5.57, Vite 8.3, TypeScript 6.0;
- Tailwind CSS 4.3, bits-ui, shadcn-svelte-компоненты, иконки Phosphor;
- TS-типы DTO из Rust через `ts-rs`;
- данные — JSON-файлы (`library.json`, `settings.json`, `matches.json`), без SQLite.

## Что готово

- **Гараж:** скан папки и подпапок игры, карточки и виртуальный список, фильтры
  и поиск, выбор (клик, Ctrl, Shift, галочки) и действия над пачкой, копии и прошлые
  версии, удаление с отменой, исправление упаковки, превью из архивов.
- **Игра:** `db.json`, включение и выключение как в игре, игровой помощник
  `bmm_bridge.zip` для открытой игры, версия игры, моды из `repo`; папка игры — из
  Steam (реестр и библиотеки), по запущенному процессу и из `startup.ini`.
- **Установка:** zip/rar/7z, перетаскивание, «Из архива», наблюдение за «Загрузками»
  и своими папками, проверка безопасности, вложенные модпаки, перепаковка, откат.
- **Поиск:** Modland, STMods, ModsGaming; одинаковые моды с разных сайтов — одна
  карточка; ручные решения по дублям; разделы «Машины / Карты / Дополнения» с
  догрузкой; фильтры, сортировка, операторы `автор:`, `тип:`, `сайт:`; подсказки;
  транслит и синонимы, если ничего не нашлось; повтор одного сайта.
- **Обновления:** проверка при запуске, по расписанию и вручную, один мод, пропуск
  версии, отказ от проверки, подбор и проверка страниц на других сайтах, потерянные
  страницы, состояние сайтов, ETag/Last-Modified, Retry-After. «Обновить» открывает
  окно загрузки: страница мода, этапы, перехват архива, проверка и установка.
- **Программа:** portable-выпуск, самообновление с GitHub (размер, SHA-256, атомарная
  замена exe, откат), окно с объяснением при отсутствии WebView2, один экземпляр,
  настройки, темы, акценты и фоны, режимы движения «Живо» / «Быстро».

## Проверки

CI на `windows-2025` (`.github/workflows/ci.yml`) на каждый push и PR: `svelte-check`,
Vitest, сборка фронтенда, `cargo fmt`, `clippy -D warnings`, `cargo test`; на `main`
ещё и полная release-сборка exe. На 2026-10-30:
**739 тестов Rust** (2 пропущены намеренно) и **126 тестов интерфейса**.

Отдельно проверяется связка окна и Rust: каждый `invoke()` попадает в команду с теми
же аргументами, типы DTO генерируются из Rust, строковые значения сверяются с
`unions.ts`.

## Известные ограничения

- **1.0.4 не обновляется сама** — один раз вручную (описано в README).
- **В 1.0.4 и 1.0.5 окно загрузки открывалось без панели шагов** («404 Not Found»):
  панель грузилась по адресу `/download.html`, которого не знает роутер интерфейса.
  Исправлено в 1.1.0.
- Страницы сайтов меняются: парсеры проверяются на сохранённых страницах
  (`fixtures/`) и требуют обновления, когда сайт меняет вёрстку.
- Системное «уменьшить движение» намеренно не переопределяет выбор «Живо» / «Быстро».
