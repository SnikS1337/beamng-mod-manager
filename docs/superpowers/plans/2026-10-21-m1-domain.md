> **Исторический документ.** Описывает старую C#/WPF-версию или ранний этап переезда. Не является текущей инструкцией. Актуальные сведения — в `README.md`, `docs/STATUS.md` и `docs/BUILD.md`.


> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Цель:** перенести в `bmm-domain` настройки, библиотеку, решения по дублям, разбор названий, версии, платность и matcher так, чтобы старые файлы читались без потерь, а 60+ доменных тестов старого проекта были воспроизведены в Rust.

**Архитектура:** чистые модули без Tauri, сети и игры. Файловые хранилища терпимы к мусору, пишут атомарно и возвращают предупреждения, как C#-версия. Старый код в `legacy/` — эталон; расхождения запрещены.

**Стек:** Rust 1.99, serde + serde_json, chrono, url, fancy-regex, json5, thiserror, tempfile.

**Спека:** [docs/superpowers/specs/2026-10-21-rust-tauri-refactor-design.md](../specs/2026-10-21-rust-tauri-refactor-design.md)

## Общие ограничения

- Windows x64 — целевая сборка; тесты должны работать и на Windows, и на Linux (без Windows API в домене).
- Форматы `settings.json`, `library.json`, `matches.json` совместимы со старой версией:
  PascalCase в settings/library, lower-case в matches; enum’ы в settings — числа, в library — строки;
  даты — ISO-8601 с offset; UTF-8 без BOM; отступ 2 пробела.
- Неизвестные поля игнорируются; повреждённый файл уходит в `*.bad-<yyyyMMdd-HHmmss>` и не теряется.
- Все записи атомарные: временный файл, `sync_all`, переименование; временный файл удаляется при ошибке.
- Никаких паник на пользовательских данных; ошибки — `Result`/`thiserror`.
- Тексты предупреждений и названия тестов — по-русски, как в старом проекте.
- Проверки: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test -p bmm-domain`.
