# M4: сайты и поиск — состояние

Дата: 2026-10-22. Ветка: `refactor-rust-poc`.

## Готово

- `bmm-sources::net`: HTTP-клиент на reqwest/native-tls — User-Agent, таймауты 15/30 с,
  cookie jar, gzip/brotli/deflate, редиректы, лимит ответа 16 МиБ, определение кодировки
  (заголовок, BOM, meta, windows-1251 как запасной вариант), разбор `Retry-After`.
- Вежливый слой: один запрос на хост, пауза 1.5 с + джиттер до 1 с, кэш успешных страниц
  30 мин / 64 записи, повторы 429/503 (с `Retry-After`), один повтор 502/504/520–524,
  cooldown после трёх сбоев на 10 мин, защёлка Cloudflare (`NeedsHumanCheck`), сброс источника.
- `parsers`: BeamNG (XenForo), Modland, ModsGaming (uCoz), STMods; общие помощники для
  HTML-сущностей, тегов, размеров (`КБ/МБ/ГБ`, запятая, пробелы), дат (epoch, XenForo, ISO).
  Разбор списков, поиска, карточек, превью, внешних и платных ссылок.
- `sources`: контракт `ModSource` и четыре адаптера с реальными URL, формами STMods,
  двумя выдачами ModsGaming, фильтрами «это страница мода» и лентой каждого сайта.
- `search`: параллельный опрос сайтов, промежуточные ответы по мере готовности, отмена,
  лимит 30 записей на сайт, `NewestOnly` по версии/автору, слияние только уверенных дублей,
  «возможно, тот же мод», ручные решения из `matches.json`, цены Free/Paid/Mixed,
  релевантность и транслит для широкой выдачи ModsGaming.
- Tauri: `search_start` (события `search://event`), `search_cancel`, `search_decide`;
  состояние поиска в `SearchRuntime`, отмена предыдущего запроса, защита от паники,
  отметка «Установлен» по привязкам, URL и нормализованному названию библиотеки.
- UI: экран «Поиск» — поле запроса, панель сайтов (идёт/проверка/недоступен/сколько нашлось),
  скелеты, карточки с источниками, версиями, авторами, размерами, ценами, кнопками
  «Скачать/Открыть/Купить», решения «Это один мод / Это разные». Mock-режим в браузере
  повторяет поток, отмену и слияние.

## Проверено

- 222 теста Rust: 88 домена, 4 совместимости, 25 игры, 58 архивов, 8 Tauri, 39 источников
  (сеть на локальном HTTP-сервере, все парсеры на реальных фикстурах, адаптеры, дедупликация,
  версии, цены, релевантность, потоковый поиск).
- Браузер: пустой экран → запрос `bmw` → потоковые источники и карточка с двумя сайтами →
  «Установлен»/«Платно»; запрос с дублем → «Это один мод» → карточки слились.
- `cargo fmt`, clippy `-D warnings`, `svelte-check`, `npm run build`, Tauri debug build — зелёные.
- CI предыдущего M3-коммита `999b243` — успешно.

## Ограничения

- Превью сайтов пока не проксируются: CSP не пускает чужие картинки, карточки показывают
  градиент с первой буквой. Каталог `SearchPreviews` уже зарезервирован — загрузка/кэш
  картинок следующим шагом (M5).
- 20-секундный дедлайн на источник из спеки не прерывает уже начатый HTTP-запрос: у клиента
  свой таймаут 30 с; остальные сайты при этом продолжают приходить потоком.
- Кнопки «Скачать/Купить» открывают страницу или файлхост в браузере; скачивание и установка
  из найденного — M5.
- Modland при Cloudflare показывает «проверка»; встроенное окно WebView2 для прохождения —
  M5. HTTP-клиент использует свои cookies, они не общие с окном.
- Ленты сайтов готовы в backend, но экран «Обновления» и планировщик — M5.
- Включение сайтов берётся из сохранённого `DisabledSources`; экран настроек — M6.
