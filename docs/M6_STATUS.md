# M6: настройки, темы и загрузки — состояние

Дата: 2026-10-22. Ветка: `refactor-rust-poc`.

## Готово

- Tauri: `settings_load` / `settings_save`, полный DTO настроек, нормализация и клампы
  выполняются доменным `AppSettings`, всё сохраняется в тот же `settings.json`.
- Экран «Настройки»: режим (тёмная/светлая/системная), 5 фонов, жидкое стекло, анимации,
  движение фона, огоньки, наклон, папки модов и пользователя, число копий,
  предупреждение о включённых модах, наблюдение за папками, TTL и лимиты проверки,
  автопроверки, включение/выключение сайтов.
- Применение оформления: `appearance.svelte.ts` ставит классы `dark`, `no-glass`,
  `no-motion`, `no-background`, `theme-*`; добавлены палитры Deep/Dusk/Forest/Graphite.
- Наблюдение за «Загрузками» и добавленными папками: фоновый сканер раз в 600 мс,
  файл предлагается после 1,5 с неизменного размера; событие `incoming://download`,
  скачанные не-моды и уже установленные молча пропускаются, остальные открываются
  в окне проверки. Учитывается `AllowDownloads`, `WatchFolders` применяются на лету.
- Автопроверка обновлений: при `AutoCheckOnStart` через 8 с после старта и далее по
  `AutoCheckEveryHours` (0 — выключено), в фоне, без блокировки окна.
- Окно Modland для прохождения Cloudflare (`updates_open_modland`), кнопки
  «Открыть Modland» и «Я прошёл» в панели сайтов.
- `bmm-app-release`: портирован self-update — строгий `latest.json`, GitHub/https,
  размер и SHA-256, загрузка в `.part` с прогрессом/отменой, безопасное извлечение exe,
  подготовка, подмена с откатом, Unicode-пути, `*.old`/`*.new`/`*.bad`, локальная лента.
  42 теста. Tauri-команды и UI — следующий шаг M7.

## Проверено

- 448 тестов Rust: 42 self-update, 92 проверок обновлений, 16 Tauri, 110 домена,
  4 совместимости, 29 игры, 83 архивов, 72 источников.
- Браузер: настройки загружаются, «Лес» сохраняется и меняет палитру; темы/режимы/
  галочки применяются; сканер загрузок покрыт тестами на стабильность/расширения.
- `cargo fmt`, clippy `-D warnings`, `svelte-check`, `npm run build`, Tauri debug build,
  запуск собранного окна на отдельном `LOCALAPPDATA` — зелёные.

## Осталось

- M7: Tauri-команды проверки/загрузки/перезапуска self-update, плашка обновления,
  обработчик `--install-update`, portable-релиз `BeamModManager.exe` + `latest.json`,
  CI-публикация, удаление `legacy/` после полного паритета.
- Modland: окно проверки открывается, но HTTP-поиск использует отдельные cookies;
  для полного обхода Cloudflare нужен маршрут страниц Modland через WebView2.
- Скачивание из поиска: кнопки ведут на страницу/файлохост, готовый файл подхватывает
  наблюдатель «Загрузок». Прямая загрузка ModsFire/MediaFire не автоматизируется.
- Огоньки и наклон фона пока только настройки без визуального эффекта — полировка M6.
- Тур первого запуска и подсказки — полировка после функционального паритета.
