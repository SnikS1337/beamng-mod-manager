# PoC: Rust + Tauri 2 + Svelte 5

> **Исторический документ.** Описывает старую C#/WPF-версию или ранний этап переезда. Не является текущей инструкцией: актуальные сведения — в [README](../README.md), [STATUS](STATUS.md) и [BUILD](BUILD.md).


Проверочный скелет нового стека для ModManager BeamNG. Существующее приложение на .NET/WPF не тронуто:
всё лежит в отдельном каталоге `poc/`.

## Стек

- **Rust** 1.99 (edition 2024), **Tauri 2**
- **Svelte 5** (runes) + **SvelteKit** (SPA, `ssr = false`)
- **TypeScript** 6, **Vite** 8
- **Tailwind CSS 4** через `@tailwindcss/vite`
- **shadcn-svelte** 1.7 (button, switch, badge; зависимости `bits-ui`, `tailwind-variants`)

## Что проверяет

| Проверка | Как посмотреть |
|---|---|
| Окно без нативной рамки, свои кнопки | заголовок окна, кнопки справа |
| CSS-стекло, анимированный фон, темы | правая панель → «Жидкое стекло», «Тёмная тема» |
| Виртуализация 5 000 карточек | прокрутка сетки; в панели «Карточек в DOM» |
| IPC Rust ↔ Svelte | `poc_library` отдаёт 5 000–20 000 записей; видно «IPC, мс» |
| shadcn-svelte + Tailwind 4 | кнопки, переключатели, бейджи, тема |
| Отдельное окно Modland | кнопка «Открыть окно Modland» |

FPS считается через `requestAnimationFrame` и обновляется раз в 0,5 с. Для замера прокручивайте сетку
несколько секунд и смотрите значение в правой панели.

## Запуск

Нужны Rust (rustup), Node.js 22+ и системные зависимости Tauri для вашей ОС.

```bash
cd poc
npm install

# полноценное окно Tauri (нужен Rust)
npm run tauri dev

# только интерфейс в браузере: данные генерируются в TypeScript,
# кнопки окна и Modland ничего не делают
npm run dev
```

Проверки:

```bash
npm run check     # svelte-check + TypeScript
npm run build     # сборка фронтенда
cd src-tauri && cargo check

# дымовая проверка: сразу открыть окно Modland
npm run tauri -- dev -- -- --probe
```

## Что уже проверено (2026-10-21, macOS)

- `npm run check` — 0 ошибок и 0 предупреждений, `npm run build` собирается;
  `cargo check` и `cargo build` проходят (Rust 1.99, Tauri 2.12).
- Нативное окно Tauri без рамки открывается (1280×820 по центру). IPC работает:
  `poc_library` вернул 5 000 записей, `poc_environment` — сведения о среде.
- Второе окно Modland создаётся (1100×800). Cloudflare и общие куки не проверялись:
  на Windows это WebView2, на macOS — WKWebView, поведение разное.
- Сетка на 5 000 модов держит в DOM около 12 карточек — видно в правой панели
  «Карточек в DOM»; прокрутка не создаёт карточки целиком.
- Вид проверен снимком из headless Chrome. Нативный снимок macOS снять не удалось
  (нет разрешения записи экрана), поэтому FPS и поведение верхушки (перетаскивание,
  разворот, прилипание) нужно проверять руками на Windows — там целевая платформа.

## Что осознанно не входит

Это скелет, а не миграция. Следующие рискованные части нужно проверять отдельными PoC:

1. **Самообновление.** Tauri updater ставит NSIS-инсталлятор; портативная замена exe с откатом
   и четырьмя CI-сценариями требует своего кода на Rust.
2. **RAR/7z и безопасная распаковка.** Нужны `zip`, `sevenz-rust`, `unrar` и повторная проверка
   symlink/archive-bomb защиты.
3. **Modland и Cloudflare.** Сейчас открывается отдельное окно WebView с сайтом. Общие куки,
   перехват загрузок и повторный опрос после проверки не сделаны.
4. **Точное стекло.** CSS `backdrop-filter` даёт близкий, но не идентичный WPF/HLSL результат.
   Для преломления и линз, скорее всего, понадобится WebGL-слой.
5. **CI и релизы.** Снимки, замеры, self-update-сценарии и выпуск пока остаются в старом workflow.

`csp: null` в `tauri.conf.json` — только для PoC; в рабочей сборке нужен строгий CSP.

## Следующий шаг после PoC

Если окно и прокрутка 5 000 карточек устраивают по FPS и виду — переносить ядро модулями:
сначала парсеры сайтов и установку архивов на Rust с текущими фикстурами, затем экран «Моды»,
затем обновления/поиск/настройки. WPF-версия остаётся эталоном для сравнения снимков.
