# M2: игра, скан модов и экран «Моды» — состояние

> **Исторический статус этапа.** Зафиксирован на дату в заголовке; текущее состояние проекта — в [STATUS.md](STATUS.md), актуальное руководство — в [README](../README.md) и [INFO](../INFO.md).


Дата: 2026-10-21. Ветка: `refactor-rust-poc`.

## Что сделано

- `bmm-game`: поиск папки пользователя и `mods` (startup.ini, current, версии, 0.100 > 0.39,
  проверка записи), версия игры из INI/лога, совместимость, определение процесса игры.
- `db.json`: терпимый разбор, ключи как в Lua (только латиница в нижний регистр), repo-данные,
  `active`, backup `db.json.bmm-bak`, атомарная запись, все исходы старого `SetActive`.
- `bmm-domain`: `DiskMod`, разбор имени файла (`BindingSuggester`), сверка библиотеки с диском:
  новые, удалённые, изменённые, переименования, пустая/недоступная папка, регистр.
- `bmm-packs`: обход `mods` и подпапок, скрытие `bmm_bridge.zip`, `unpacked`/symlink,
  нормализованный ZIP-индекс, выбор превью (vehicle/level/mod_info/app/any, текстуры,
  размеры из заголовков без декодирования), кэш превью и `titles.json`, обзор архива
  (машины/карты/скрипты/файлы/размер, обёрточная папка, `info.json`).
- Tauri: состояние с настройками/библиотекой/кэшем, `library_load`, `library_refresh`,
  `mod_toggle`, `mod_details`, `mod_preview`, протокол `bmm-preview://` (Windows:
  `http://bmm.localhost/preview/...`), pending-очередь в `pending.json`.
- Svelte: экран «Моды» — заголовок, фильтры с числами, поиск (токены-префиксы),
  виртуальная сетка 2–6 колонок, карточки с реальными превью, выбор, инспектор,
  «Внутри архива», совместимость, переключение, тост с «Отменить», клавиши Ctrl+F/Esc/Space/стрелки,
  пустые состояния, mock-режим на 5000 карточек.

## Известные ограничения UI

- Инспектор скрывается при ширине ≤900 CSS px (в Tauri 1280 он есть).
- Счётчик «Не проверяются» показывает моды без подтверждённой привязки; сам фильтр пока пуст.
- В браузерном mock-режиме превью нет — только градиенты.

## P0-оптимизации после аудита (2026-10-21)

- Первый скан 5000 модов пишет `library.json` **один раз**: `reconcile` и `apply_repo_info`
  обёрнуты в `batch()`.
- В снимке больше нет O(n²): один скан `bindings`/`checks`, индексы `filename → DiskMod`,
  `id → binding`, `id → key превью`, набор подтверждённых привязок, pending читается один раз.
- Превью ограничены семафором на 4 параллельных извлечения; карточки не устраивают шторм
  `spawn_blocking`.
- У `bmm-desktop` убран лишний `staticlib` из `crate-type` (остался `rlib`); это уменьшает
  `.lib`-артефакт. Старые файлы в `target/` нужно удалить отдельно: Cargo не чистит их сам.
- Убрана отладочная строка «N модов · в DOM» из UI.
