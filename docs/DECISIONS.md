# Принятые решения

Что в программе сделано намеренно и не должно «чиниться» без нового решения.
Каждый пункт — правило и короткая причина. Если правило меняется, сначала правится
этот файл.

## Моды и игра

- **Моды — обычные файлы игры.** Программа не прячет их и не меняет формат без
  действия человека; удалите программу — включённые моды останутся. Выключенные
  переносом и копии прошлых версий лежат в папке программы: перед удалением её
  их нужно включить или перенести (INFO, «Где данные и как удалить»).
- **Включение и выключение — как в самой игре:** флажок `active` в `db.json`, перед
  правкой копия `db.json.bmm-bak`. Мод, который игра ещё не видела, выключается
  переносом файла в папку программы.
- **Открытая игра подхватывает изменения на лету.** При запущенной игре переключение
  идёт через игровой помощник `bmm_bridge.zip` (программа сама кладёт его в `mods`).
  Отложить до закрытия игры — только запасной путь, если помощник не отвечает.
  Пачка модов уходит помощнику одной командой; ответа ждём не дольше 30 секунд —
  всё это время библиотека занята, а неотвеченная команда у игры уже есть и
  применится сама (повторно «до закрытия» её не откладываем).
- **Моды из `repo` (скачанные в самой игре) не удаляются и не переупаковываются** —
  ими управляет игра.
- **Копии одного мода — одна карточка самого свежего.** Остальные видны в панели мода;
  сами ничего не выключаем, даже если включено несколько.
- **У дополнений нет картинки из архива** — там случайные текстуры. Вместо неё значок
  и подпись.
- **«Такая машина уже стоит» — только предупреждение.** Исполняемые файлы в архиве —
  предупреждение с выбором (бывают честные), опасные пути и имена — запрет.
- **Удаление обратимо:** файл уходит в копии, есть «Отменить» и фильтр «Удалённые».

## Сайты и обновления

- **Поиск — только по страницам модов BeamNG:** Modland, STMods, ModsGaming, ModHub.
  Репозиторий BeamNG используется для обновлений, не для поиска.
- **Все сайты по умолчанию включены, в том числе Modland и ModHub** (они за Cloudflare).
  Проверку «вы человек?» проходит человек во встроенном окне; программа её не решает.
- **У каждого сайта своё окно проверки «вы человек?»** — пока одно долго грузится,
  можно пройти другое. Второе окно того же сайта не открывается (показывается первое).
- **Прошли проверку сайта — проверяется только этот сайт**, а не все: остальные о
  проверке не просили. Если в это время идёт другая проверка, сайт ждёт её конца;
  пройденные сайты проверяются по очереди, каждый отдельно.
- **Не обходим капчи, таймеры, рекламу и платные стены.** Платные моды показываются
  с меткой «Платный» и ведут на страницу автора; программа их не скачивает.
- **«Обновить все» — очередь страниц, установка в конце.** В пачку идут только уверенные
  обновления; Download на каждой странице нажимает человек, архивы проверяются и
  ставятся одним списком.
- **«Обновить» одинаково везде** — в «Обновлениях», в панели мода, на карточке и в её
  меню: окно загрузки, а если оно недоступно — браузер и «Загрузки». Если сайт
  обновления не открывается, вопрос про запасной сайт задаётся в разделе
  «Обновления» (туда и ведёт гараж), чтобы он был в одном месте.
- **Окно загрузки ничего не нажимает само.** Download нажимает человек; программа
  перехватывает только архивы `zip`, `rar`, `7z`, всё остальное не скачивается.
- **Страница мода:** уверенное совпадение — программа следит сама; сомнительное
  (или без размера и автора) — предложение, которое подтверждает человек.
- **У мода может быть несколько страниц — по одной на сайт.** Вторые страницы
  программа добавляет сама только при уверенном совпадении и только по «Найти
  страницы»; там, где человек отказался от страницы или проверки, не ищет.
- **Пропавшую с сайта страницу программа сама не снимает** — показывает в «Страницах»:
  найти новую или перестать следить.
- **Сайтам — вежливо:** один запрос за раз на сайт, паузы, ETag/Last-Modified,
  уважение к Retry-After, пауза после серии сбоев. Сбой одного сайта не мешает
  остальным.
- **Размеры на сайтах — двоичные МБ** (1 МБ = 1024 КБ), как пишут сами сайты.
- **Картинки сайтов хранятся на диске до 300 МБ**, давно не нужные уходят при запуске;
  в настройках («Сайты») видно, сколько занято, и есть «Очистить». Какой файл какой
  картинке соответствует, программа помнит между запусками — картинки выдачи
  встают сразу, без запроса. Обложки модов и картинки выдачи WebView держит в
  памяти: имя файла меняется вместе с содержимым.

## Программа

- **Портативный exe без установщика.** Данные — в `%LOCALAPPDATA%\BeamModManager`.
- **Подписи exe нет** — SmartScreen предупреждает, это описано в README.
- **Самообновление пишет новую версию в тот же файл** одной операцией
  (`ReplaceFileW`), прежняя остаётся для отката. Если новая версия не показала окно —
  упала, вышла сама или висит дольше двух минут — откат (копия рядом и
  переименование), и эта версия больше не предлагается.
- **Анимации — только по настройке программы** («Живо» / «Быстро»). Системное
  «уменьшить движение» выбор не переопределяет. Двигаем только `transform` и
  `opacity`; правила — в [MOTION](MOTION.md).
- **Уведомлений Windows нет.** У переносной программы без установщика они приходят
  от имени PowerShell с его значком (так устроены уведомления Windows; см.
  документацию Tauri). Вместо них, если проверка нашла обновления, пока окно
  свёрнуто или в стороне, мигает кнопка программы на панели задач; ход загрузок и
  проверки виден там же полосой.
- **Пиксели картинок модов может читать только сама программа:** адрес
  `bmm.localhost` разрешает это только для origin окна программы, а не для сайтов,
  открытых в окне загрузки.
- **Без размытия (blur)** под панелями и на карточках: на сетке из тысяч модов это
  заметная нагрузка.
- **Кант карточки и свет панели мода — цвета акцента темы**, а не цвета обложки:
  оттенок обложки на большинстве карточек не читался (серые, тёмные картинки) и
  прыгал от мода к моду. Кант тонкий всегда, под курсором ярче.
- **Фон окна — цвета темы** (`window_background`): пока WebView перерисовывает
  страницу после «Развернуть», видно окно, а не чёрный прямоугольник.
- **Фон программы дешёвый для перерисовки:** свой слой (`contain: strict`), зерно —
  готовая картинка, без смешивания слоёв (`mix-blend-mode`), SVG-шума и размытия
  (тест `renderCost`). Без видеокарты (виртуальная машина, «Microsoft Basic Render
  Driver») WebView рисует всё процессором, и тяжёлый фон давал секунды чёрного окна.
- **Окна проверки сайтов — поверх программы** (принадлежат главному окну) и при
  двух окнах делят экран пополам; кнопка сайта, чьё окно открыто, показывает его.
- **На карточке тип и состояние справа, галочка выбора слева** — выбирая галочками,
  видно, что за мод.
- **Галочки на карточках собирают пачку, не открывая панель мода** — иначе сетка
  перестраивалась бы под курсором. Смена вида «сетка ↔ список» — без перетекания
  карточки в строку.
- **Шрифты, иконки и всё остальное — внутри программы**, без внешних адресов (CSP).
- **Одно правило толщины иконок Phosphor:** заглушки вместо картинки (машина, карта,
  коробка…) — `thin`; мелочь до 13 px в метках и галочки, крестик «закрыть» — `bold`;
  обычные 14–24 px — `regular`, активное — `fill`; крупнее — `thin`. Исключения
  перечислены с причиной в `src/lib/shell/iconWeights.test.ts`, тест проверяет все
  `.svelte`.
- **Метки типа и состояния — со значком** (`features/garage/tagIcons.ts`): одна
  таблица на карточку, строку списка, панель мода и поиск.
- **Сайты обозначены своими монограммами (ML, ST, MG, MH, BN), а не логотипами
  сайтов:** чужие логотипы пришлось бы держать внутри программы и следить за их
  сменой, а монограмма в цвете сайта читается так же быстро (`shell/siteMark.ts`).
- **Свои классы не называем как утилиты Tailwind** (`ring`, `border`, `shadow`…):
  Tailwind 4 подхватывает такое слово из исходников и вешает свою обводку.
- **Имена крейтов без «update», «install», «setup»:** Windows UAC считает такой exe
  установщиком и требует повышения прав.

## Код и работа

- **TS-типы для окна генерируются из Rust** (`ts-rs`, `src/lib/ipc/generated.ts`);
  строковые значения — в `unions.ts` и сверяются тестами. Имена команд и аргументов
  `invoke()` тоже проверяет тест.
- **TypeScript остаётся 6.x**, пока SvelteKit не поддерживает 7 (SvelteKit 3.1
  требует `typescript ^6`). **Tauri 3** —
  только после стабильного выпуска.
- **Каждая найденная ошибка — с тестом;** новое поведение покрывается тестами сразу,
  по сценариям использования.
- **Ветки:** основная — `main`, работа идёт в одной ветке `dev` (новых веток под
  задачи не заводим); после зелёных проверок и CI — fast-forward в `main`. Выпуск —
  только по решению владельца проекта.
- **Общие замки в `src-tauri` — только через `crate::state::lock`:** упавший поток не
  должен ронять программу при следующем обращении (тест следит).
- **Имена файлов в одной папке не совпадают без учёта регистра** — на Windows
  `foo.svelte.ts` и `Foo.svelte` для сборки один файл (тест следит). Тесты, читающие
  исходники, учитывают переводы строк Windows (CRLF).
- **Тексты — по-русски, без жаргона.** Про проверку архива — нейтрально
  («проверка безопасности»), без «проверки структуры».
