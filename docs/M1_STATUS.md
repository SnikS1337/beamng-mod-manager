# M1: домен и данные — состояние

Дата: 2026-10-21. Ветка: `refactor-rust-poc`.

## Что сделано

- `bmm-domain` собирается отдельно от Tauri и окна.
- Настройки: `AppSettings` схема 2, нормализация, числа для enum’ов, терпимое чтение
  `settings.json`, карантин битых файлов, атомарная запись через `sync_all` + rename.
- Библиотека: модели модов, привязок, проверок, истории, отказов и подбора страниц;
  `InMemoryLibraryStore` и `JsonLibraryStore` с batch, save_error, save_blocked, карантином
  и старой формой `library.json` (PascalCase, enum-строки, `PageSearches`).
- Решения по дублям: `matches.json` в старом lower-case формате, нормализация ключей,
  симметрия, откат при ошибке записи.
- Тексты: `TitleParser`, `TitleNormalizer`, `ModTitles` с прежними регулярками и правилами.
- Версии: `VersionComparer` (включая pre-release), `SizeComparer` с допуском, `UpdateDecider`.
- Платность: `PaidDetector` с положительными признаками бесплатности.
- Матчинг: `DuplicateMatcher` с весами 0.50/0.20/0.15/0.10/0.05, порогами 0.9/0.7
  и ручными решениями.
- Хосты: `HostLinkParser` для ModsFire/MediaFire, списки известных и платных хостов.

## Тесты

- 74 модульных теста домена + 4 интеграционных в `crates/bmm-domain/tests/compat.rs`.
- Покрыто: настройки (все поля, типы, карантин, старые версии), библиотека (round-trip,
  batch, плохие записи, сбои записи, mtime, enum’ы и даты), matches (формат, ключи, откат),
  тексты (все примеры из старых тестов), версии/pre-release/размеры, платность,
  matcher (вес имени, автор, размер, превью, общий файл, ручные решения), хосты.

## Отличия, допустимые и проверенные

- Даты в UTC пишутся как `Z`, старый C# писал `+00:00`; обе формы — RFC3339, читаются
  обеими версиями. Смысл дат не меняется.
- Порядок ключей в `library.json` фиксированный (`Schema`, `Mods`, `Bindings`, `Checks`,
  `Sources`, `Dismissed`, `History`, `Declined`, `PageSearches`), как в старом файле.
- Порядок модов при записи — по имени без учёта регистра, как `InMemoryLibraryStore`.
