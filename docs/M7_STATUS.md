# M7: self-update и portable-релиз — состояние

Дата: 2026-10-22. Ветка: `refactor-rust-poc`.

## Готово

- `bmm-app-release` (42 теста): строгий `latest.json` (https + GitHub, версия, размер,
  SHA-256, заметки), загрузка в `.part` с прогрессом/отменой, безопасное извлечение
  `BeamModManager.exe`, подготовка, запись в тот же файл с `previous.exe`, откат,
  `*.old`/`*.new`/`*.bad`, Unicode-пути, локальная лента для сборочной машины.
- Tauri-команды: `app_update_state/check/download/cancel/restart`; событие прогресса
  `app-update://event`; проверка при старте, если включено `CheckAppUpdates`.
- UI «Настройки → Программа»: текущая версия, проверка, заметки, скачивание с прогрессом,
  отмена, «Перезапустить».
- Обновление применяется отдельным процессом: `app_update_restart` запускает скачанный exe
  с `--install-update <pid> --target … --backup …`; новый процесс ждёт выхода старого,
  пишет себя на место, запускает программу; при сбое записи/запуска возвращает прежнюю.
- `.github/workflows/release.yml`: тег `v*`, проверка совпадения версии тега с
  `Cargo.toml`/`tauri.conf.json`, сборка portable exe, zip, SHA-256, `latest.json`,
  публикация GitHub Release.

## Проверено

- 459 тестов Rust: 42 self-update, 92 проверок обновлений, 22 Tauri, 110 домена,
  4 совместимости, 29 игры, 83 архивов, 77 источников.
- `cargo fmt`, clippy `-D warnings`, `svelte-check`, `npm run build`, Tauri debug build,
  запуск окна — зелёные.
- Живой поиск: STMods и ModsGaming отвечают по HTTP/2 без падений; Modland показывает
  «проверка» и кнопку «Пройти проверку». Окно само замечает, что сайт пустил, закрывается
  и продолжает поиск; капчу программа не решает. Проверено переводом окна на обычную
  страницу Modland — поиск перезапустился автоматически.
- CI на push больше не собирает release-exe: это делает release.yml на теге, а полную
  сборку можно запустить вручную (workflow_dispatch). Быстрая обратная связь — fmt,
  clippy, тесты, типы и сборка фронтенда.
- Браузер: «Настройки → Программа» показывает доступную версию, скачивание переводит
  в «готова», кнопка «Перезапустить» появляется.

## Осталось до полного паритета

- Проверить реальный тег и публикацию (workflow готов, но не запускался).
- `legacy/` оставлен как эталон по решению пользователя; удаление не планируется.
- Modland: страницы и превью идут через встроенный WebView2, как в legacy; Cloudflare может
  попросить проверку — в поиске есть «Пройти проверку», окно само закрывается после неё.
  Программа проверку не обходит и капчу не решает.
- Прямая загрузка из поиска (ModsFire/MediaFire) не автоматизируется; наблюдатель
  «Загрузок» подхватывает готовый файл.
- Тонкая полировка UI/анимаций и подписи exe (SmartScreen) — после баг-фикса.
