# Фаза 0: что проверить на Windows

Ничего из списка пока не проверено: игра удалена, доступа к Windows нет.

## Игра и папка модов

- [ ] Путь к папке модов на установке из Steam (по официальной статье: папка `mods` внутри папки версии игры в пользовательской папке; точный путь подтвердить).
- [ ] Содержимое `db.json`: какие поля игра пишет для модов из репозитория (ID ресурса, версия, дата). По исходникам BeamMM точно известно только поле `active`.
- [ ] Совместимость формата `db.json` с текущей версией игры (BeamMM не обновлялся с сентября 2024).
- [ ] Откуда читать версию установленной игры.
- [ ] Проверка: мод, положенный вручную в папку, виден в игре.

## Репозиторий BeamNG

- [ ] Есть ли интерфейс для сторонних программ; как к нему обращается встроенный менеджер.
- [ ] Условия использования.
- [ ] Номер в конце адреса страницы мода (например `6x6-d-series.22055`) как стабильный ID (подтверждено только по описанию стороннего скрипта).

## Сайты

- [ ] Modland: механика скачивания бесплатных модов, ToS, robots.txt.
- [ ] ModsGaming: страница мода, куда ведёт «Скачать», размер и автор.
- [ ] STMods: причина бесконечных редиректов, структура, ToS.
- [ ] ModsFire: второй шаг скачивания, ToS, наличие официального способа интеграции.

## Защита от неопределённости

Формат `db.json` изолирован за одним интерфейсом, неизвестные поля сохраняются как есть
(как в BeamMM), запись включается только после проверки на реальном файле.
