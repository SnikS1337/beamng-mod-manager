# Движение и анимации в интерфейсе

Актуально на 2026-11-08. Стек: SvelteKit 3, Svelte 5, Tauri 2 / WebView2.
Документ описывает то, что реализовано в `src/`.

## Режимы

- **Живо** — анимации включены.
- **Быстро** — `html.no-motion`: Svelte-переходы получают `duration: 0`, а CSS-анимации
  и переходы отключаются общим правилом в `src/app.css`. Это глобально, а не только
  для длительностей из токенов: мигание сайтов, полоса проверки, окна и переключатели
  тоже останавливаются.
- **Живой фон** — отдельная настройка, но работает только при включённых анимациях.
- Системный `prefers-reduced-motion` намеренно не переопределяет выбор пользователя
  (см. [DECISIONS](DECISIONS.md)).

## Правила

- **Двигаем только `transform` и `opacity`** (и отдельные `translate`/`scale`) — без
  перерисовки, на композиторе. Тени, размеры и цвет не анимируем, кроме коротких
  вспышек на маленьких элементах.
- **Своя анимация и отклик на нажатие не спорят:** проявление карточки при прокрутке
  двигает `translate`/`scale`, а нажатие — `transform`.
- **Бесконечная анимация в «Быстро» обрывается на последнем кадре.** Бегущие полоски
  (загрузка на обложке, ход сайта, общая полоса) для этого режима переопределены:
  стоят во всю ширину, бледнее. Кольцо у «Отменить» в «Быстро» скрыто.
- **Имя перехода уникально в каждом виде.** Где элемент «переезжает» (прилёт мода,
  обложка в панель), имя сначала стоит только на исходном элементе, а в новом виде —
  только на целевом; иначе браузер отменяет переход.
- **Intro в `{#key}` не играет при появлении блока** (переходы Svelte 5 локальные):
  «прокрутка» версии срабатывает только при смене, а не при прокрутке гаража.

## Кривые

- `--ease-out` — обычное торможение; `--ease-in-out` — для бегущих полос.
- `--ease-spring` — пружина с перелётом ~1.5% (`linear()` с 29 точками), для
  переездов карточек, панели мода, переключателя. `spring()` в
  `src/lib/shell/transitions.ts` — та же кривая для JS-переходов; тест сверяет их.
- `--ease-snap` — пружина бодрее (~12%), для мелочей: галочка, вспышка.

## Уровни движения

| Что | Технология | Где |
| --- | --- | --- |
| Маршруты, вкладки, фильтры, панель мода, сетка/список, удаление и возврат | View Transitions API | `src/lib/shell/motion.svelte.ts`, `src/app.css` |
| Прилёт установленного мода, обложка в панель | View Transitions с общим именем | `arrival.svelte.ts`, `features/garage/coverFlight.svelte.ts` |
| Окна, палитра, тосты, версия на карточке | Svelte transitions (`pop`, `softFade`, `rollIn`) | `src/lib/shell/transitions.ts` |
| Проявление карточек при прокрутке | CSS `animation-timeline: view()` | `ModCard.svelte` |
| Карточки, состояния, скелеты, ход сайтов | CSS keyframes с токенами `--dur-*` | `src/app.css`, компоненты |
| Свет фона | CSS keyframes на `transform`; пауза, пока окно скрыто или свёрнуто | `Background.svelte` |
| Переключатели, кнопки, нажатие, наведение | CSS transitions | `app.css`, компоненты |
| Вращение «пока занято» с разгоном и доворотом | Web Animations API | `src/lib/shell/spin.ts` |

## View Transitions

- `motion.run(update, scope)` запускает `document.startViewTransition`, считает
  вложенные переходы и снимает класс области после завершения. `motion.settled` —
  промис «последний переход доигран или оборван».
- Новое действие обрывает недоигранный переход; клик, пришедший во время перехода,
  повторяется по новому DOM.
- У `ViewTransition.ready` есть `.catch`: при пропуске WebView2 не пишет
  `Uncaught (in promise)`.
- Имена карточек — 64-битный хеш id (`flowName`).
- Области (класс на `<html>`): `flow-route`, `flow-garage`, `flow-section`,
  `flow-search`, `flow-view`, `flow-arrive`.
- **Гараж:** карточки (пружиной), сетка и боковая панель. Сетка и список замеряют
  размер до снимка нового вида (`motion.measure`).
- **Удаление и «Отменить»:** библиотека перечитывается до перехода (экран не замирает
  на время запроса), а применяется одним переходом вместе со снятием выбора
  (`applyLoaded` в `features/garage/view.ts`). Возвращённая карточка встаёт на своё
  место: порядок — порядок записей библиотеки, запись живёт, пока жив тост.
- **Прилёт мода** (`flow-arrive`): окно установки зовёт `arrival.fly`, гараж —
  `arrival.landed`, когда карточка на экране. Переход ждёт гараж не дольше 1,2 с;
  гаража нет на экране — всё меняется сразу. Svelte-исчезновение окна в этой области
  выключено (`motionDuration` = 0), иначе полупрозрачное окно попало бы в снимок.
- **Обложка в панель** (`flow-garage`): только когда панель открывается для одного
  мода и его карточка на экране. Пока данные мода грузятся, панель показывает уже
  известную обложку карточки — летит картинка, а не серая заглушка.
- Смена вида «сетка ↔ список» — простая смена (`flow-view`).
- Настройки и «Обновления»: меняется только содержимое раздела, шапка стоит.

## Svelte transitions

- `pop` — подъём и масштаб пружиной, прозрачность без перелёта. Окна, палитра, тосты,
  подсказка клавиш.
- `softFade` — подложки и карточки поиска, приходящие по мере ответа сайтов.
- `rollIn` — «счётчик»: версия на карточке и в списке, число выбранных модов.
- Длительность — через `motionDuration`: в «Быстро» и во время прилёта мода она 0.

## Мелкие отклики

- Нажатие: кнопки опускаются на 1 px, карточка проседает до 98,5%.
- Быстрые действия на карточке выезжают снизу обложки под курсором.
- Вторая включённая копия: метка «копии» вздрагивает (`conflictFlash`).
- Закрытый этап в окне загрузки: кружок заливается и «щёлкает», галочка
  дорисовывается.
- Кольцо у «Отменить» убывает за срок тоста и стоит, пока курсор на тосте
  (`ringTiming` в `toasts.svelte.ts`).
- Ход проверки по сайтам: точка «дышит», полоска заполняется, закончивший сайт
  «щёлкает» зелёным или красным.
- Подсказка при перетаскивании архива: стрелка разворачивается, если брать нечего.

## Живые иконки

- **Навигация:** у пункта лежат обе толщины значка; при смене раздела контур тает
  чуть крупнее, а заливка вырастает из 82% пружиной — значок «наполняется».
  Нажатие слегка сжимает значок.
- **Вращение «пока занято»** (`spinWhile` в `src/lib/shell/spin.ts`, Web Animations,
  только `transform`): «Обновить» в гараже и «Обновления» в навигации, пока идёт
  проверка (своя или фоновая).
  - Разгон: пол-оборота с ускорением; кривая подобрана так, что в конце разгона
    скорость ровно как у вращения. Вращение заводится сразу с задержкой на время
    разгона — без кадра стоянки между ними.
  - Остановка: вперёд до ближайшей половины оборота (у значка две стрелки — он
    симметричен), но не ближе 45°; ровное торможение — начальная скорость кривой
    равна скорости вращения в момент остановки. Последний кадр держится, следующий
    разгон начинается с того же угла.
  - Работа заняла миг — значок всё равно делает плавные пол-оборота.
  - Работа началась снова, пока значок доворачивался, — сразу полный ход с текущего
    угла. В «Быстро» не крутится.
- **Галочка «дорисовывается»** (`DrawCheck.svelte`): кружок появляется пружиной,
  штрих проводится по `stroke-dashoffset`. Этапы в окне загрузки; отметка
  «Установлен» на карточке и галочка в строке списка после установки
  (`installedFlash`, 1,8 с, включается после посадки «прилёта»). В «Быстро» галочка
  сразу стоит готовой, а отметка — без движения, пока её не снимет таймер.

## Производительность и ограничения

- Анимируются только видимые карточки; список и сетка виртуализированы.
- Фон двигается только `transform`; `will-change` снимается в режиме «Быстро»; при
  скрытом или свёрнутом окне свет и огоньки стоят.
- Оттенок панели по обложке считается один раз на картинке 16×16 и запоминается.
- Размытия (`backdrop-filter: blur`) в интерфейсе нет: на сетке из тысяч карточек
  это заметная нагрузка.
