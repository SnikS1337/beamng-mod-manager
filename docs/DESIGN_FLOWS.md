# Дизайн: сценарии, состояния, окно

Дополнение к [DESIGN.md](DESIGN.md) и [DESIGN_COMPONENTS.md](DESIGN_COMPONENTS.md). Здесь: где в
интерфейсе живёт каждая функция из [PLAN.md](PLAN.md), что человек видит в каждом сценарии, что
показывать, когда пусто или сломалось, как ведёт себя окно, горячие клавиши.

Пометки: **нарисовано** (есть в макете), **решение** (принято здесь, не нарисовано, не проверено
на Windows), **открыто** (нужен ответ заказчика, список в разделе 9).

## 2. Окно и размеры

- **Окно без стандартной полосы заголовка** (решено 2026-10-14, нарисовано на доске «Гараж»). Фон доходит до самого
  верха окна. «Свернуть», «Развернуть», «Закрыть» — стеклянная капсула в правом верхнем углу; при наведении под кнопкой
  появляется капля жидкого стекла и перетекает между кнопками, под «Закрыть» она красная (привычно по Windows,
  единственное место с красным). Название
  приложения в окне не пишем: оно видно в панели задач и при Alt+Tab. Окно перетаскивается за любое пустое место
  фона и верхней панели. Обязательно сохранить привычное поведение Windows (проверить в первую очередь):
  раскладки окна при наведении на «Развернуть» (Windows 11), двойной клик по пустому месту разворачивает,
  перетаскивание к краю экрана прилипает, растягивание за края, Alt+Пробел открывает меню окна, тень и скругление
  окна системные. В WPF это `WindowChrome` (или полоса заголовка из WPF-UI) плюс ответ системе, где кнопки
  (`WM_NCHITTEST`), иначе раскладки Windows 11 не появятся.
- **Размер по умолчанию** 1440 × 960 (размер макета), запоминается между запусками. Минимальный
  1000 × 680. На экране меньше 1440 × 960 окно открывается по размеру экрана минус рамка.
- **Три класса ширины** (решение):

| Ширина окна | Поведение |
| --- | --- |
| 1360 и больше | как в макете: левая панель, сетка, правая панель |
| 1100–1359 | сетка в 3 колонки, правая панель те же 328 px |
| 1000–1099 | правая панель закрыта; при выборе мода выезжает поверх сетки справа с затемнением, Esc закрывает |

- **Сетка** подбирает число колонок: ширина карточки не меньше 280 и не больше 340,
  промежуток 20, остаток делится поровну. Высота карточки считается от ширины (фото 16:9).
- **Высота.** Левая панель привязана к левому верхнему углу; правая панель начинается под капсулой кнопок окна
  и занимает высоту окна минус 80. Меньше 680 по высоте не бывает (минимум окна).
- **Масштаб Windows** 100–200 %: всё в независимых единицах WPF, размеры карточек и текста растут
  вместе. Проверяем на 125 и 150 %. При 200 % включается класс ширины по реальным пикселям.
- **Полноэкранное окно.** Сетка растёт в колонки до 6, правая панель остаётся 328.
- **Закрытие во время работы.** Проверка обновлений и поиск отменяются без вопросов, найденное
  сохраняется. Если идёт установка, при закрытии диалог «Установка не закончена. Подождать или
  отменить?» с главной кнопкой «Подождать».

## 3. Сценарии

Каждый сценарий: шаги человека, что он видит, чем закончилось. «→» — переход.

### 3.1 Первый запуск (решение)

Окно открывается на стене без панелей, по центру плашка 560 шириной (не стекло):
1. «Найдём ваши моды». Программа ищет папку игры (подсказка по Steam). Если нашла: «Нашли
   BeamNG.drive: C:\… Использовать?» с кнопками «Использовать» и «Выбрать другую».
   Не нашла: поле выбора папки с пояснением, как выглядит нужная папка.
2. Показываем итог: «Нашли 24 мода» → кнопка «Открыть гараж».
3. Короткая подсказка поверх гаража, один раз, три пузыря по очереди: «Здесь ваши моды»,
   «Здесь появляются обновления», «Здесь настройки». Кнопки «Дальше» и «Пропустить».

Загрузка модов на этом шаге **не предлагается**: она выключена по умолчанию (PLAN.md раздел 2).
Игры не нашли и человек отказался выбирать: открывается пустой гараж (4.1) и в нём строка «Укажите
папку модов в настройках».

### 3.2 Найти мод и поставить

1. «Поиск» → ввод названия, Enter. Результаты приходят по мере ответов сайтов: сначала скелеты,
   потом карточки, панель «Сайты» показывает, кто ответил.
2. Карточка: «Установить» (белая) или «Страница» (если загрузка выключена, только «Страница»).
3. «Установить» → окно загрузки (нарисовано). Человек сам нажимает кнопки на странице хоста.
4. Файл пришёл → «Архив проверен» → «Установить» → тост «Мод установлен» с кнопкой «Показать в гараже».
5. Карточка в гараже появляется с обводкой и выбранной (выбран только что установленный).

Платный мод: на шаге 2 вместо «Установить» «Купить у автора», открывается страница автора в
обычном браузере. В программе мод не скачивается и не появляется.

### 3.3 Обновить мод

1. Бейдж «3» на «Обновлениях» (виден с любого экрана) → раздел «Обновления».
2. Карточка «Есть новая версия» → «Обновить».
3. Окно загрузки (как 3.2), в проверке дополнительно строка «Прошлая версия 1.0 останется в копиях».
4. После установки: тост «Обновлено до 1.5. Прошлая версия в копиях» + «Вернуть». Карточка уходит из
   ленты плавно (550 мс), бейдж уменьшается.
Без включённой загрузки вместо «Обновить» кнопка «Открыть страницу»: человек обновляет сам, а
программа замечает новую версию при следующей проверке.

### 3.4 Вернуть прежнюю версию или удалённый мод

- Сразу после действия: «Отменить» в тосте (8 с). Пока тост открыт, интерфейс не сверяет библиотеку с папкой:
  иначе запись мода и привязки удалились бы вместе с файлом (AUDIT.md, «Известные ограничения»).
- Позже: правая панель мода → «Прошлые версии» → «Вернуть» напротив версии. Тост «Вернули 1.0».
- Удалённый мод: фильтр «Удалённые» **не вводим**; удалённые моды лежат в «Прошлых версиях» не
  существующего мода, поэтому нужна отдельная точка входа: «Настройки → Обновления → Копии»
  (решение) со списком «Удалённые моды» и кнопкой «Вернуть».
  В ядре это `VersionHistory.Deleted` и `VersionHistory.RestoreDeleted` (не сырой `ModInstaller.DeletedMods`: в нём есть прежние имена обновлённых модов); «Прошлые версии» мода: `VersionHistory.For / Restore`.

### 3.5 Включить и выключить

Пробел на выбранной карточке, «Выключить» в панели, меню карточки. Фото плавно уходит в серый
(550 мс), тост «Выключен» с «Отменить». Если игра запущена, в тосте добавлена строка «Изменения
применятся при следующем запуске игры». Состояние игры (запущена или нет) определяем по процессу,
если не получилось, строку показываем всегда (**не проверено**).

## 5. Сбои и редкие ситуации

Каждое состояние уже имеет решение в ядре ([UPDATE_CHECK_EDGE_CASES.md](UPDATE_CHECK_EDGE_CASES.md));
здесь то, что видит человек. Тексты — из компонентов раздел 5.2.

| Ситуация (ядро) | Что видит человек | Где |
| --- | --- | --- |
| Проверка идёт | кнопка «Проверить сейчас» заменена на «Остановить», рядом прогресс «12 из 38» и кольцо | панель «Проверка» |
| Нажали сразу после проверки (`FreshSkipped`) | «Проверено 6 минут назад. Новое смотрим не чаще раза в 6 часов», кнопка «Всё равно проверить» | панель «Проверка» |
| Проверка отменена | «Остановлено. Найденное сохранено» | панель «Проверка» |
| Проверка неполная (`Complete = false`, `Postponed`, `StoppedByTime`) | «Проверили 20 из 38. Остальные при следующей проверке» и причина по сайтам | панель «Проверка»; слов «всё актуально» нет |
| Сайт недоступен | строка сайта: янтарная точка и «Не отвечает, попробуем через 5 минут» | панель «Проверка», «Сайты» |
| Сайт просит подтвердить человека (`NeedsHumanCheck`) | строка сайта: «Нужна проверка» и кнопка «Открыть сайт»; после неё «Готово» | панель «Проверка», «Настройки → Сайты» |
| Пустая лента, «изменились адреса или вёрстка» | «Возможно, сайт изменился. Мы его временно не проверяем» | строка сайта |
| Карточка пропала у одного мода | карточка мода «Страница пропала» (после двух промахов) | «Обновления» |
| Нет сети | полоска над сеткой «Нет соединения. Гараж работает, поиск и проверка недоступны» | сверху области сетки |
| Папка модов недоступна во время работы | диалог «Не видим папку модов» + «Указать папку», пока не указана, действия с модами неактивны | диалог |
| Файл мода не читается | карточка с заглушкой и словом «Не читается», в панели «Удалить» и «Открыть папку» | гараж |
| Повреждены настройки | тост «Часть настроек сброшена. Старый файл сохранён» | один раз при запуске |

Правило: одна проблема — одно место показа. Не дублировать тостом то, что уже стоит строкой в

## 6. Диалоги и составные экраны (решение)

Диалог — плашка 440 (компоненты 3.8). Кнопки справа, главная первой.

### 6.1 Указать папку

Выбор папки системным окном, потом строка проверки словами. Главная кнопка «Использовать»
неактивна, пока папка не подходит (подсказка почему).

### 6.2 Пропустить эту версию

Без диалога. Тост «Версия 1.5 скрыта. Другая версия снова покажет обновление» + «Отменить».
Скрытые видны в «Обновления → Скрытые».

### 6.3 Не проверять этот мод

Без диалога, тост с «Отменить». Мод переходит в фильтр «Не проверяются», в «Обновлениях» исчезает.
В ядре: `BindingActions.Decline`, отмена `BindingActions.Undo` (возвращает привязки, проверки и пропущенную версию).

### 6.4 Указать страницу мода

Диалог. Вверху фото и название мода. Поле ввода ссылки (компоненты 3.4). Ниже подсказки из
поиска по названию: до трёх карточек «Modland · Toyota Sienna v2.2» с выбором одной. Главная
«Следить на этой странице» активна после успешной проверки ссылки. После — тост «Следим на Modland».

### 6.5 Найти замену

Диалог на тех же элементах, что 6.4. Заголовок «Страница пропала. Вот похожие моды»,
до трёх кандидатов (поиск по названию и автору, без самой мёртвой страницы). Выбор кандидата
и «Следить здесь». Внизу вторичная «Не проверять этот мод». Ничего не привязывается без выбора.

### 6.6 Возможно, тот же мод

В поиске, если схожесть 0,7–0,9: карточка с плашкой «Возможно, тот же мод» и двумя
текстовыми действиями «Это один мод» и «Это разные». Выбор запоминается навсегда и меняет
карточку на объединённую или две отдельные. До выбора карточки не объединены.

### 6.7 Ошибки окна загрузки

Состояния, которые нужно нарисовать к готовности (шаблон тот же, меняется шаг и сообщение):
- **Файл удалён с хоста.** Шаг 1: «Хост сообщает, что файл удалён» и «Открыть страницу мода».
- **Скачивание прервалось.** «Загрузка прервалась на 64 %. Нажмите Download ещё раз».
- **Архив подозрителен.** Состояние «Архив проверен» с янтарной строкой про найденное (программы,
  скрипты вне ожидаемых папок). Главной становится «Не устанавливать» (белая), а «Установить
  всё равно» вторичная (контур). Проверка структуры ничего не гарантирует, так и пишем.
- **Не архив мода.** «В архиве нет папки vehicles или levels. Это не похоже на мод» и «Закрыть».
- **Всплывающее окно хоста заблокировано.** Тихо, полоса «Заблокировали рекламу, открывшуюся
  отдельным окном».

### 6.8 Совместимость с версией игры

Строка в блоке данных: «Для игры 0.38, у вас 0.39». Янтарная точка только если версии
различаются на минорную или больше; слова «Может не работать». Версия игры берётся из папки
пользователя BeamNG (**не проверено**); если версию не нашли, строки нет. Не блокирует действия.

### 6.9 Много активных модов

Если включено больше порога (по умолчанию 30), над сеткой один раз за запуск появляется строка
`rgba(255,255,255,.12)` высотой 40: «Включено 34 мода. Игра может грузиться дольше» и «Понятно». Не тост
и не диалог: это сведение, не ошибка.

## 7. Клавиатура

| Клавиша | Действие |
| --- | --- |
| Tab и Shift+Tab | по порядку: левая панель, верхняя панель, сетка, правая панель |
| Стрелки | выбор карточки в сетке; внутри группы фильтров между пунктами |
| Enter | открыть выбранный мод (в правой панели); в диалоге нажимает главную кнопку |
| Пробел | включить или выключить выбранный мод; в списке настроек переключить |
| Delete | «Удалить» выбранный мод (с тостом «Отменить») |
| Ctrl+F | поиск по гаражу |
| Ctrl+Shift+F | раздел «Поиск» |
| Ctrl+R или F5 | проверить обновления |
| Ctrl+1, 2, 3 | Гараж, Обновления, Поиск |
| Ctrl+, | Настройки |
| Esc | закрыть диалог, правую панель (узкое окно), очистить поле |
| Меню или Shift+F10 | меню выбранной карточки |

Конфликтов с Windows нет, кроме F5 (в WPF свободна). Всё **не проверено** на Windows. Подсказки
с клавишами показываем в тултипах: «Настройки (Ctrl+,)».

## 8. Звук и системные уведомления

- **Звуков нет.** Игра и так шумная, программа не добавляет шум.
- **Системных уведомлений Windows нет**, программа не живёт в трее и ничего не делает, пока
  закрыта. Проверка обновлений идёт при запуске и по кнопке (решено 2026-10-14). Повторная проверка, пока окно
  открыто, есть в настройках, по умолчанию выключена. Всё идёт через один координатор, чтобы
  автоматическая и ручная проверки не пересекались. Найденное видно бейджем на «Обновлениях».
  Фоновая проверка при закрытой программе — отдельное решение, нужны согласие и настройка
  (открытый вопрос 5).
- **Значок на панели задач**: без счётчиков, только значок приложения.
