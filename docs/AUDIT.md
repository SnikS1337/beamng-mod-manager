# Сквозной аудит (по темам, а не по модулям)

Проход по модулям пропускает баги на стыках. Поэтому для каждой темы ниже задаются одни и те же вопросы ко всему коду.
Пункты, которые без Windows и игры проверить нельзя, вынесены в конец («Для этапа с Windows»). Общее состояние: [STATUS.md](STATUS.md).

## Найдено и исправлено сквозным проходом

| Тема | Что было не так | Что сделано |
|---|---|---|
| Состояние: диск ↔ библиотека | Библиотека нигде не сверялась с папкой модов. Удалили, переименовали, обновили мод руками — запись и «обновление» устаревали навсегда | `LibrarySync.Reconcile`: добавляет новые, убирает исчезнувшие, ловит смену размера, отключение, переименование (привязки остаются у того же мода) |
| Состояние: диск недоступен | Пустой снимок папки (диск отключён) стёр бы все привязки, которые пользователь настраивал вручную | Пустая или недоступная папка при непустой библиотеке: сверка пропускается, причина возвращается в отчёте |
| Файлы: обновление под другим именем | Новая версия `audi_v1.5.zip` рядом со старой `audi_v1.0.zip`: в игре два одинаковых автомобиля | `ModInstaller.Update`: старая уходит в резервные, отключённый остаётся отключённым, при сбое новая откатывается |
| Идентичность мода | После обновления под новым именем создавался бы новый мод без привязок | `RecordInstalled(replacesFileName)` и переименование при сверке сохраняют тот же Id |
| Профили | Профиль хранит имена файлов: после обновления старое имя «пропадало», а новый файл профиль отключал | `ProfileService.ApplyRenames` |
| Ручная замена файла | Версия в записи оставалась старой, «обновление» висело вечно | Версия из имени файла, иначе с сайта (если размер совпал), иначе «неизвестна» |
| Настройки: загрузка | Настройка «Разрешить загрузку» нигде не проверялась в одном месте | `DownloadPolicy`: единый вход (настройка, сайт, платное, https, известный хост) |

## Ревизия новых функций ядра (2026-10-14)

Проверено при добавлении ручных решений по дублям, возврата версий, настроек и «Не проверять этот мод»:

| Тема | Что проверено | Итог |
|---|---|---|
| Идентификатор копии | Путь вне папки копий, `..`, абсолютный путь, пустая строка, чужое имя | Принимается только имя файла, лежащее в папке копий этого мода; остальное отказ |
| Возврат версии с другим именем | Занято имя возвращаемой версии, текущего файла нет, отключённый мод, сбой переноса, шесть возвратов подряд | Одна включённая версия, текущий файл при сбое возвращается на место, ничего не затирается |
| Ошибка записи решений на диск | Нельзя создать папку или записать файл | Исключение выходит наружу, в памяти остаётся прежнее состояние (найдено и исправлено при ревизии) |
| Файл решений и настроек | Мусор, не тот формат, неверные типы, числа вне диапазона, лишние поля | Карантин или пропуск записи с предупреждением, значения приводятся к допустимым |
| Отказ от проверки | Переименование файла, ручная привязка, удаление мода, мода нет | Отказ переживает переименование, снимается подтверждённой привязкой, чистится с модом |
| Пересборка карточек | Решение «разные» для одной пары из трёх, «один мод» при слабых признаках | Нет обращений к сайтам, нет склейки через третью запись |
| Прежнее имя после обновления (повторная проверка) | `car_v1.0.zip` после обновления до `car_v2.0.zip` попадал в «Удалённые моды»; «Вернуть» поставило бы v1 рядом с v2 | Исправлено: `VersionHistory.Deleted` отсеивает прежние имена (история и то же название мода), они видны в «Прошлых версиях» |
| Посторонние файлы в папке копий (повторная проверка) | `desktop.ini` или `Thumbs.db` от Проводника считались копией; «Вернуть последнюю» поставило бы его вместо мода, чистка могла удалить настоящую копию | Исправлено: копией считается только «номер_время_имя» |
| Ручное «Это один мод» (повторная проверка) | Запись уходила в чужую карточку, если там автоматическая оценка была выше | Исправлено: карточка с ручным решением в приоритете |
| Пересборка карточек (повторная проверка) | Порядок записей брался из карточек, а не от сайтов: «Вернуть как было» могло дать другие карточки | Исправлено: ответ хранит записи в исходном порядке |
| Предупреждение сборки CA2255 | `ModuleInitializer` в библиотеке | Намеренно (таймаут регулярных выражений до первого разбора), подавлено с пояснением |

## Темы, по которым вопросы заданы, а дефектов не найдено

- Время: часы назад и вперёд, ограничение по секундомеру, порядок резервных копий (см. [TIME.md](TIME.md)).
- Редкие заходы: страницы лент, проверка карточек порциями, автоматические партии (см. [UPDATE_CHECK_EDGE_CASES.md](UPDATE_CHECK_EDGE_CASES.md)).
- Повторные нажатия и отмена: единый запуск, отмена с повтором.
- Нет сети: сайты помечаются недоступными, сохранённые данные не меняются, запросов в пустоту немного.
- Пустая библиотека, ни одного сайта, только неподтверждённые привязки.
- Странные запросы поиска: пустые, спецсимволы, очень длинные, управляющие символы.
- Две записи на одну страницу.

## Решения пользователя и известные ограничения

- Проверка обновлений при запуске включена по умолчанию (`AutoCheckOnStart`), повторная по расписанию выключена (`AutoCheckEveryHours = 0`); решено заказчиком.
- Известное ограничение: удаление мода из менеджера при следующей сверке убирает запись и привязки. Мод, возвращённый из «Удалённых», появится как новый, без привязок. «Отменить» в тосте сразу после удаления работает, если интерфейс не сверяет библиотеку, пока тост открыт (DESIGN_FLOWS.md 3.4).

## Для этапа с Windows

Порядок работы и сценарии: [STATUS.md](STATUS.md) раздел 4, [PHASE0.md](PHASE0.md), [WINDOWS_SCENARIOS.md](WINDOWS_SCENARIOS.md).

- `ModInstaller.Update`: сбой «старый файл занят игрой» проверен подменой (резервная папка занята файлом); поведение при настоящей блокировке файла проверить на Windows.
- Регистр имён файлов: на Windows `Audi.zip` и `audi.zip` один файл; в тестах на Linux регистр различается.
- Сверка при запущенной игре (игра может держать файлы).
