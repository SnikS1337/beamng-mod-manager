# План проекта

Дата: 2026-10-13. Всё, что помечено «не проверено», нужно подтвердить на Windows
(см. [PHASE0.md](PHASE0.md)). Актуальное состояние и что осталось: [STATUS.md](STATUS.md). Дизайн интерфейса:
[DESIGN.md](DESIGN.md) (в интерфейсе профили не нужны, остаются фильтры: решено, STATUS.md 3.3).

## 1. Цель и принципы

Менеджер модов для BeamNG.drive (Steam, Windows) для личного использования.

- Менеджер первичен, загрузка опциональна и выключена по умолчанию.
- Не обходим платные стены, капчи, таймеры и рекламу; клики на странице файлообменника делает пользователь.
- Платный мод показываем, ведём на страницу автора, не скачиваем. Функцию «найти бесплатную копию платного мода» не делаем.
- Точность важнее полноты при объединении дублей.
- Один адаптер на каждый сайт; сбой одного не ломает остальные.
- `db.json` игры пока только читаем, запись включаем после проверки формата на реальном файле.
- Моды содержат Lua-код: проверка архива и откат обязательны.

## 2. Режимы и настройки

Главная настройка: **«Разрешить загрузку модов»** (по умолчанию выключена).

| Функция | Загрузка выключена | Загрузка включена |
| --- | --- | --- |
| Библиотека, профили, вкл/выкл, резервные копии | да | да |
| Проверка обновлений (репозиторий и привязанные страницы) | да | да |
| Поиск по сайтам | да, карточки и «Открыть страницу» | да |
| Кнопки «Скачать» и «Установить» | скрыты | есть |
| Окно ModsFire и перехват загрузки | не создаётся | есть |
| Автоустановка скачанного файла | нет | да, после подтверждения |

Другие настройки: папка игры и папка модов (выбор вручную, автоопределение Steam только как
подсказка), список включённых источников, частота проверки обновлений (по умолчанию раз в
сутки), предупреждение о числе активных модов (по умолчанию больше 30).

## 4. Архитектура

Интерфейс (WPF + WPF-UI) и окно загрузки (WebView2, только при включённой загрузке)
обращаются к ядру (.NET 8, без интерфейса). Ядро: поиск и дубли, установка, обновления,
профили. Ядро ходит к адаптерам сайтов, репозиторию BeamNG, SQLite и папке модов игры.

Адаптер сайта: `search`, `listing`, `latest`, `offers`. Источники отключаются по одному.

## 5. Модель данных (SQLite, FTS5)

| Сущность | Что это |
| --- | --- |
| Listing | Запись об одном моде на одном сайте: источник, URL, ID, название, версия мода и игры, автор, категория, размер, превью, цена (`free`/`paid`/`unknown`), время первого и последнего просмотра |
| Offer | Способ получить файл: тип (`direct`/`external_host`/`paid_link`), хост, URL, ID файла на хосте, статус |
| Mod | Единый мод после объединения дублей: список Listing, лучший источник, ручные решения |
| Installed | Установленный мод: файл, исходный Listing, версия, размер, хеш архива, отпечаток содержимого, дата, резервная копия |
| Binding | Привязка установленного мода к странице: ссылка, последняя версия, размер, хеш описания, «игнорировать версию» |
| Profile | Набор модов |

Относительным датам сайтов не верим: пишем момент, когда сами заметили изменение.

## 6. Поиск и объединение дублей

Живой поиск: параллельно во все включённые адаптеры, таймаут 5–8 с, карточки по мере ответов.

Нормализация названия: нижний регистр, без «МОД», «ДЛЯ BEAMNG.DRIVE», версии, версии игры
в скобках, `v`, `[PACK]`, `Update 2!`, пунктуации; сравнение по токенам.

Признаки: название, автор, категория, версия игры; размер (±несколько процентов); хеш превью;
**ID файла на ModsFire** (одна ссылка = один файл); отпечаток содержимого архива (после скачивания).

Пороги: от 0,9 объединяем; от 0,7 до 0,9 «возможно, тот же мод» с кнопками объединить и
разделить; ниже 0,7 разные. Ручные решения сохраняются навсегда.

Платные: признаки PAID/Premium/VIP/Early Access, единственная ссылка на Patreon, Boosty,
Gumroad, Ko-fi, BuyMeACoffee, цена на странице. Неопознанное = `unknown`, не «бесплатно».
Платный оригинал показывается первым; возможный перезалив получает метку
«возможно неавторизованная копия». Числа скачиваний у сайтов не складываем.

Первые тестовые пары: Toyota Sienna 2011-2017 v2.2 и 2021-2024 Nissan Kicks v1.1
(есть на Modland и ModsGaming).

## 7. Загрузка (только при включённой настройке)

1. Пользователь нажимает «Скачать»; лаунчер показывает данные страницы хоста (имя, размер, дата, «файл удалён»), если они видны до кликов.
2. Открывается окно WebView2 на странице ModsFire; всплывающие окна и чужие домены блокируются.
3. Пользователь сам проходит все кнопки и таймеры.
4. Лаунчер перехватывает начало загрузки, показывает прогресс, закрывает окно.
5. Проверка: архив, размер, zip-slip, архивные бомбы; RAR и 7z перепаковываются в ZIP.
6. Снимок состояния, установка в папку модов, запись в базу.

Запасной путь: обычный браузер и отслеживание папки «Загрузки». Это не убирает шаги и рекламу
ModsFire; убирает рутину после клика. Premium оставляем на потом (место в резолвере хоста).

## 8. Обновления

Проверяются только установленные моды (десятки запросов в сутки). Работает и без загрузки:
сообщает «есть обновление» и открывает страницу.

- Официальный репозиторий: читаем данные игры о таких модах и спрашиваем репозиторий о новой версии.
  Для модов не из репозитория ищем одноимённый по названию и автору.
- Привязанные страницы: ссылка вводится пользователем (или выбирается из подсказок); раз в сутки
  проверяются только они.

Определение «есть обновление», по порядку: версия из заголовка (`1.3.2`); размер и хеш файла;
хеш блока описания; момент, когда мы впервые заметили изменение. Ложные срабатывания
допустимы: «возможно, обновлено» + «Игнорировать эту версию». Предупреждение о совместимости
с версией игры. Молчаливых обновлений нет: сохраняется старый архив, откат одной кнопкой.

## 9. Безопасность и правила

- Только HTTPS, проверка размера и хеша; защита от zip-slip и архивных бомб.
- Структурная проверка: нет `.exe`, `.dll`, `.bat`, `.sh`, скриптов вне ожидаемых папок, подозрительно крупных файлов. Это эвристика, не антивирус.
- Метки доверия: официальный репозиторий, привязанный автор, сторонний сайт.
- Снимок и откат перед каждым обновлением; лаунчер сам ничего не запускает.
- Вежливый клиент: честный User-Agent, не чаще 1 запроса/с на хост, кэш, `If-Modified-Since`/ETag, пауза при ошибках, `robots.txt`, ленивые картинки. Полный обход сайтов не делаем.
- У каждого адаптера тесты на сохранённых HTML и контрольный запрос; при поломке источник помечается «не работает». Защиту от ботов не обходим.
- Перед разработкой читаем ToS, DMCA и `robots.txt` сайтов; в карточке всегда «Открыть на сайте».

| --- | --- | --- |
| 0. Проверка на Windows | Формат `db.json`, путь к папке модов, правила сайтов | Мод, положенный вручную в папку, виден в игре |

Без Windows можно делать ядро целиком (адаптеры с тестами на сохранённых страницах, дубли,
SQLite, обновления, проверка архивов, работа с фальшивой папкой `mods`). Интерфейс и окно
WebView2 можно написать на Mac, но нельзя запустить, поэтому они последние.
