# Что нового

Коротко, по строке на заметное изменение. Раздел «## версия» обязателен: без него выпуск не соберётся.

Последний опубликованный выпуск — **1.0.5**.

## Не выпущено
- Окно загрузки скачивает только архивы модов: установщик или другой файл со страницы не ложится молча в «Загрузки», панель пишет «Это не архив мода».
- Карточка: тип слева, состояние справа, ничего не наезжает на картинку; галочка выбора появляется на месте типа при наведении и у всех карточек, пока выбрано несколько.
- Аудит безопасности архивов: имена 7z/RAR проверяются до распаковки (потоки NTFS, `CONIN$`, `..`), число записей zip читается из EOCD до разбора, отвергнутые по размеру картинки не хранятся сырыми, `taskkill` запускается из System32.
- Аудит сети: старые http-ссылки поднимаются до https, понижение схемы в редиректе запрещено; картинки ждут общую очередь сайта, а одинаковые версии и перепосты в поиске склеиваются.
- Аудит данных: библиотека переживает битую запись, длинные имена копий открываются по verbatim-пути, имя копии резервируется через `create_new`, удаление убирает обе копии имени, Unicode-формы и регистр имён сравниваются одинаково.
- Аудит проверки обновлений: отчёты всех пачек сливаются, выключенные сайты не попадают в план, моды, подтверждённые лентой, считаются проверенными, пачки не выходят за план страниц.
- Аудит игры: Steam находится через реестр (`SteamPath`), `.EXE` в любом регистре распознаётся, версия игры берётся из строки `version=` и лога.
- Аудит интерфейса: сбой фоновой перезагрузки гаража показывает баннер и не стирает список, прошлые версии перечитываются после восстановления, настройки сохраняются сразу, тосты идут очередью, Esc в поле ссылки не чистит поиск.
- Аудит самообновления: неудачная подготовка убирает распакованный exe, новая загрузка чистит старые попытки, пометка о неудачном запуске пишется атомарно и живёт неделю.
- Поиск: если основной запрос ничего не нашёл, сайты пробуются ещё по транслиту и знакомым синонимам («Лада Нива» → `lada niva`, `vaz` → `lada`).
- Поиск: фильтры по типу, цене, установленным, сайту и совместимости с версией игры, сортировка по релевантности, новизне или размеру; выбранные фильтры запоминаются.
- Поиск: операторы `автор:`, `тип:` и `сайт:` прямо в строке, клик по автору в карточке фильтрует выдачу, у мода в гараже есть «Открыть в поиске».
- Поиск: «Скачать» открывает встроенное окно загрузки, а у вопроса о дублях видно, что совпало — автор, версия или размер.
- Поиск: подсказки из недавних запросов и установленных модов, без сети; выбор мышью или стрелками.
- Поиск: упавший сайт можно повторить отдельно, не перезапуская весь поиск.
- Поиск: разделы «Машины», «Карты» и «Дополнения» открываются без текста на STMods, ModsGaming и Modland (cars, maps, other) и листаются по две страницы с каждого сайта; «Показать ещё» добавляет следующие, повтор упавшего сайта работает и в разделе.
- Поиск: слово «карта» (как и «машины» или «дополнения») открывает нужный раздел, а не ищет его как текст.
- Поиск: тип карточки больше не путает карту с машиной из-за слова «конфигурации» в описании STMods; название и адрес мода важнее описания.
- Поиск: верх страницы собран в одну панель — категории со счётчиками, «Фильтры» и сортировка под рукой, без двух рядов чипов.
- Тема: переключение светлой, тёмной и системной темы раскрывается тем же кругом от клика, что и смена акцента; элементы больше не остаются в старом цвете.
- Настройки: «Программа» стала «О программе» — версия, проверка обновления, ссылки на GitHub и релизы, папка данных и свёрнутое «Что нового».
- Проверка Modland: окно проверки принудительно перезагружает страницу после метки, поэтому подтверждение «я человек» наконец замечается; ожидание больше не сдаётся через полторы секунды.
- Поиск: в разделе карт Modland больше не показывает машины, попавшие в список раздела; карточки фильтруются по разделу в их адресе.
- Устойчивость: лог игры с кириллицей на границе среза и глубокая вложенность `info.json` больше не роняют программу.
- Данные: одна битая запись библиотеки не обнуляет привязки, проверки и историю; отсутствующая `Schema` читается, более новая не перезаписывается. Если повреждённый файл не удалось убрать, настройки, библиотека и решения по дублям не перезаписываются.
- Запись: атомарная запись повторяет краткие ошибки занятости Windows и убирает старые `.tmp`; второй экземпляр в другой сессии ловится файловой блокировкой каталога данных.
- Самообновление: версия exe из ресурсов Windows снова сверяется с `latest.json`, если её можно прочитать; нечитаемая по-прежнему не блокирует установку.
- Обновления страниц: без размера и автора страница остаётся предложением, а не молчаливой привязкой; `db.json` находит кириллические имена в другом регистре; челлендж сайта получает срок и сбрасывается при новом поиске.
- Гараж: стрелки прокручивают список к выбранной карточке и передают ей фокус — Пробел управляет уже ею; окно загрузки больше не держит процесс после закрытия главного.

## 1.0.5
- «Проверить на других сайтах»: для предложенной страницы программа открывает её и ищет тот же мод на остальных включённых сайтах, сравнивая название, автора, версию и размер; ничего не привязывает без решения человека.
- Исправлено самообновление: проверка версии внутри архива больше не блокирует установку, если версию exe прочитать нельзя; причина сбоя записи показывается в плашке.
- Поиск: ModsGaming больше не падает на кириллических страницах, превью с modsgaming.us снова показываются.
- Настройки и установка: ошибка чтения не затирает файл настроек, старые `.part` убираются при запуске, один скачанный архив не предлагается дважды; перенос между дисками и атомарная запись `db.json` больше не теряют данные.
- Безопасность: окна загрузки и проверки не уходят в localhost и частные адреса, служебные диапазоны IP закрыты, архивы с именами устройств Windows (`CON`, `NUL`, `COM1`…) отклоняются.
- Проверки страниц: сеть не держит общую защёлку, отмена не снимается чужой проверкой, «Отменить» сообщает, если страницу вернуть нельзя.
- Интерфейс: палитра не стирает введённый запрос, тост не делает удаление необратимым, «Проверить на других сайтах» не блокирует остальные строки молча.

- Если у вас 1.0.4: автоматическое обновление до 1.0.5 не сработает из-за проверки версии в самой 1.0.4. Один раз скачайте `BeamModManager-1.0.5.zip` с GitHub и замените exe — дальше обновления работают сами.

- Картинки модов хранятся уменьшенными до 720 точек: сетка листается быстрее
- В окне модпака длинный список прокручивается, а не вылезает за края
- В поиске не показывается «Цена неизвестна» на каждой карточке
- Поиск: вопрос «Возможно, тот же мод» — не больше одного на карточку и только там, где склейка возможна
- Уверенно найденная страница проверяется по размеру на самой странице мода, прежде чем следить без вопроса
- Обновление под другим именем файла сохраняет страницу мода и историю; «Отменить» возвращает их
- «Исправить» больше не стирает известную версию мода
- Переименованный мод сохраняет версию; версия скачанного с сайта берётся по размеру
- Модпак из модпаков: вложенные моды больше не подменяют друг друга
- Две установки одновременно больше не пишут в один временный файл
- При закрытии программы библиотека дописывается, даже если шла проверка
- Сбой запроса к сайту больше не ломает этот сайт до перезапуска
- Сбой фоновой проверки больше не останавливает проверки по расписанию
- Название мода с ModsGaming без хвоста сайта и служебных вставок
- «Установлен» в поиске: только страница, за которой следим, без одноимённых чужих модов
- Тесты фронтенда (vitest) в CI
- «Это другой мод» и для страницы, за которой программа уже следит: в «Обновлениях» и в панели мода, с «Отменить»
- «Остановить» и таймаут поиска прерывают ожидание очереди сайта, паузы и повторы: остановленный поиск больше не держит сайт
- Архивы модов открываются за миллисекунды, а не 4–8 с на большой мод: панель мода, картинки, названия и проверка модпака больше не ждут
- «Указать страницу» в панели мода: вставить ссылку — программа откроет страницу и начнёт следить
- Распаковка модпака не ломается, если путь к архиву относительный
- При установке: «Похоже, такая машина уже стоит» — если у другого мода почти то же название машины
- Итог проверки по сайту учитывает оба хода (до и после подбора страниц): сбои первого хода не теряются
- «Обновить» открывает страницу и полчаса смотрит «Загрузки»: скачанный архив предлагается к установке, даже если наблюдение выключено
- После установки обновления пункт сразу пропадает из «Обновлений», а число на значке уменьшается
- Распаковка 7z и RAR не тормозит сама себя постоянным подсчётом размера; бюджет учитывает уже распакованное
- После закрытия окна программа полностью завершается: скрытые окна сайтов больше не держат её в памяти
- Зависимости обновлены (Tauri 2.12.5, json5 1.3, fancy-regex 0.20, sha2 0.11 и др.), разбор файлов и имён сверен до и после
- Моды для стандартных машин игры (тюнинг, двигатели, карьера) больше не принимаются за обновление друг друга — раньше установка такого мода удалила бы другой
- Имена файлов: метки сайтов и телеграм-каналов, копии «(1)», версии вида «Ver1.0», «hotw0.3.0», «2.8.0_alpha2» и склеенные слова («AstonMartinValhalla») разбираются
- Названия модов — из info.json или из имени файла, без служебных имён папок и лишних пробелов
- Программы и скрипты Windows в архиве — предупреждение с выбором, а не блок (Maserati с управлением Spotify ставится своей галочкой)
- Сборка «alpha» против той же версии на сайте без пометки решается по размеру; причина находки пишется честно, когда версия у вас не указана
- Первая проверка открывает страницу мода, если версия в ленте сайта другая, — нужен размер для решения
- Подбор страниц: совпавший автор (из архива или имени файла) помогает найти страницу с другими словами, страница автора важнее одноимённых копий, рубрики сайтов («Карта», «Мод автомобиль») не мешают сравнению
- Проверка при запуске показывает свой ход в «Обновлениях»
- Копии и версии одного мода собраны в одну карточку — самую свежую (старшая версия, затем новый файл) с меткой «Копий: N»; в её панели список копий: «Только эта», «Открыть», «Удалить». Метка красная, если включено несколько — игра загрузит все
- Архив с символической ссылкой внутри блокируется уже при проверке, а не только при распаковке
- Страница в репозитории BeamNG и версия берутся из mod_info в самом архиве — сразу, не дожидаясь запуска игры (10 из 39 скачанных модов); у модов, оформленных автором, читаются версия и название
- Дополнения (детали для машин игры, погода, скрипты, звук) показаны без картинки — с подписью «Дополнение / не машина и не карта»
- «Обновления»: «Пропустить версию» и «Это другой мод» убраны в меню «Ещё» — карточка не разъезжается на две строки
- Гараж: длинные названия в сетке занимают две строки, список на минимальной ширине не даёт горизонтальной прокрутки, а панель мода ложится поверх списка
- Поиск: в пустом состоянии есть примеры запросов; «на нескольких сайтах» вместо обещания всех сайтов
- Поиск: репозиторий BeamNG больше не показывается среди сайтов поиска — он остаётся для проверки обновлений и страниц модов
- Обновления: «Всё актуально» больше не говорится, если сайт не ответил; у каждого сайта видно время последней проверки и причину, а у проблемного — кнопку «Повторить»
- Мод: «Проверить обновления» по его странице и «Не проверять» с отменой; отказ переживает перезапуск
- Настройки проверки: можно не проверять обновления выключенных модов
- Сеть: страницы перепроверяются по ETag/Last-Modified; ответ 304 не скачивает тело заново
- Настройки: пять акцентов стоят ровной сеткой; подписи второго плана контрастнее в обеих темах
- Значки интерфейса скрыты от screen reader, список модов выбирается отдельной кнопкой, меню «Ещё» работает с клавиатуры
