# ModManager BeamNG — подробно

Что умеет программа, как работает с игрой и сайтами, где хранит данные и как собрать
её самому. Кратко — в [README](README.md), что нового — в [CHANGES.md](CHANGES.md),
текущее состояние — в [docs/STATUS.md](docs/STATUS.md).

## Что это

Портативная программа для Windows, которая держит в порядке моды BeamNG.drive:
показывает установленные, включает и выключает их как сама игра, ставит новые из
архива, следит за обновлениями на сайтах и ищет моды сразу на нескольких сайтах.
Моды остаются обычными файлами в папке игры: программу можно удалить, моды останутся.

## Установка и первый запуск

1. Скачайте `BeamModManager-<версия>.zip` из
   [последнего выпуска](https://github.com/SnikS1337/beamng-mod-manager/releases/latest)
   и распакуйте в любую папку. Устанавливать ничего не нужно.
2. Запустите `BeamModManager.exe`. Нужен Windows 10/11 и Microsoft Edge WebView2
   Runtime — обычно он уже есть вместе с Windows/Edge; .NET и другие среды не нужны.
3. Если Windows пишет «Windows защитила ваш компьютер» — программа не подписана:
   «Подробнее» → «Выполнить в любом случае».
4. Папку модов программа находит сама (обычно
   `%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods`). Не нашла — откройте настройки
   и выберите папку `mods` или папку пользователя игры.

При первом запуске показывается короткое знакомство. Его можно пройти или закрыть.

### Если WebView2 Runtime нет

Программа не сможет показать окно: Tauri на Windows работает только через WebView2.
Она покажет окно с объяснением и предложит открыть страницу загрузки. Установите
[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
(или `winget install Microsoft.EdgeWebView2Runtime`) и запустите программу снова.
Сам установщик WebView2 в наш zip не входит.

Другого движка в этой сборке нет. Если WebView2 нельзя установить из-за сломанной
Windows, понадобится отдельная сборка со встроенным fixed runtime (она заметно
тяжелее), другой движок или ремонт системы; текущий portable-архив этого не делает.

## Гараж

Показывает моды из папки `mods`, её подпапок и моды, скачанные в самой игре
(в `repo`). Карточка берёт название из `info.json` мода, из данных игры или со
страницы сайта; имя файла видно в панели мода.

- Вид: карточки или плотный список. Вид запоминается.
- Фильтры: «Все», «Машины», «Карты», «Дополнения», «С обновлением», «Без страницы»,
  «Выключены»; «Удалённые» появляется, когда есть удалённые копии.
- Поиск по своим модам: `Ctrl+F`, `Ctrl+K` — палитра команд.
- Включение и выключение — переключателем на карточке или клавишей `Пробел` для
  выбранного мода. Пока игра запущена, переключение идёт через игровой помощник.
- Выбор: клик, `Ctrl+клик`, `Shift+клик` для диапазона, `Ctrl+A` — все видимые.
  Для нескольких модов есть общая панель: включить, выключить, удалить.
- Удаление — с «Отменить» и `Ctrl+Z`; файл уходит в копии, вернуть можно и позже
  через фильтр «Удалённые».
- Правая панель: название, версия, размер, совместимость с версией игры, состав
  архива, прошлые версии с «Вернуть», копии одного мода.
- «Исправить» — переупаковать архив, который игра не видит из‑за лишней папки или
  отсутствия `vehicles/`. Прежний файл остаётся в копиях.
- Правая кнопка мыши по карточке: быстрое меню действий.

## Обновления

Программа проверяет моды на сайтах: при запуске (если включено), по кнопке и по
расписанию, пока программа открыта. Проверять можно только мод, у которого известна
его страница на сайте. У модов из репозитория BeamNG страницу знает игра; для
остальных программа ищет её по названию и предлагает подтвердить.

- «Проверить сейчас» проверяет всё, чему уже пора. Если всё проверено недавно,
  кнопка меняется на «Всё равно проверить» — тогда срок давности и кэш страниц
  игнорируются.
- «Проверить обновления» в панели мода проверяет только его.
- «Не проверять обновления» отключает проверки для одного мода; «Включить проверку»
  возвращает их.
- «Пропустить это обновление» скрывает конкретную версию в «Пропущенные»; другая
  версия снова появится в «Доступных».
- «Страницы» — найденные, но неуверенные страницы: «Следить» или «Это другой мод».
  Там же страницы, которые пропали с сайта: найти новую или перестать следить.
- Панель «Проверка» показывает ход, последнюю проверку и состояние каждого сайта;
  сайт, который не ответил, можно повторить отдельно.
- Чтобы не нагружать сайты, программа сначала читает ленты свежих модов и открывает
  карточки только тех модов, которых в ленте нет. Между запросами к одному сайту —
  пауза. Повторные запросы страниц используют ETag/Last-Modified.
- В настройках можно не проверять выключенные моды, ограничить число страниц с одного
  сайта и задать срок, в течение которого мод не проверяется повторно.

## Поиск

Один запрос — на включённых сайтах Modland, STMods и ModsGaming. Репозиторий BeamNG
в поиске не участвует. Ответы приходят по мере готовности сайтов; один мод с разных
сайтов собирается в одну карточку.

- Если программа не уверена, что записи с разных сайтов — один мод, она спрашивает:
  «Это один мод» или «Это разные». Решение запоминается.
- Платные моды помечены «Платный» и ведут на страницу автора; их программа не
  скачивает.
- «У вас стоит» — мод уже есть в библиотеке (или за его страницей следит программа).
- Фильтр типа: все, машины, карты, дополнения.
- В панели «Сайты» видно, кто ответил, сколько нашёл и кто просит проверку.

## Настройки

Настройки сохраняются автоматически между запусками.

- **Внешний вид** — тёмная, светлая или системная тема; пять акцентов; наборы
  «Живо» и «Быстро»; отдельно анимации интерфейса и живой фон. Живой фон работает
  при включённых анимациях. В режиме «Быстро» движение отключается полностью,
  включая окна, индикаторы и фоновый свет.
- **Папки** — папка модов и папка пользователя игры.
- **Моды и загрузки** — сколько прошлых версий хранить, предупреждение о большом
  числе включённых файлов, предложение установить скачанные архивы, дополнительные
  папки наблюдения.
- **Обновления** — срок повторной проверки мода, число страниц с одного сайта,
  проверка при запуске, периодическая проверка, проверка выключенных модов и
  обновлений самой программы.
- **Сайты** — какие каталоги участвуют в поиске и проверке обновлений.
- **Программа** — текущая версия, проверка, скачивание и перезапуск для обновления.

Клавиши: `Ctrl+K` — палитра команд, `Ctrl+F` — поиск, `Ctrl+Z` — отменить последнее
действие из тоста, `Ctrl+A` — выбрать все видимые моды, `Пробел` — включить или
выключить выбранный мод, `Delete` — удалить выбранные, стрелки — перейти по списку,
`Esc` — снять выбор или очистить поиск.

## Установка из архива

Перетащите на окно `zip`, `rar` или `7z`, нажмите «Из архива» или включите
«Скачанные моды» — тогда программа заметит архивы в «Загрузках» и добавленных папках.

Перед установкой архив проверяется: опасные пути, исполняемые файлы, слишком большая
распаковка, вложенные архивы. Программа показывает, что внутри: новый мод, обновление
уже установленного или такой уже стоит. Установка идёт по кнопке; прежняя версия
сохраняется копией, есть «Отменить». Архив с лишней папкой может быть перепакован,
чтобы игра увидела мод.

Сама программа моды с сайтов не скачивает: скачайте архив на странице мода и
перетащите его на окно.

## Сайты

| Сайт | Поиск | Обновления | Заметки |
| --- | --- | --- | --- |
| Modland | да | да | открывается встроенным WebView2; по умолчанию выключен, включается в настройках |
| STMods | да | да | каталог модов BeamNG |
| ModsGaming | да | да | русский каталог модов |
| Репозиторий BeamNG | нет | да | моды, скачанные в самой игре, привязываются к нему сами |

**Modland и проверка «вы человек?»** Modland защищён Cloudflare и не всегда пускает
обычный запрос. Его страницы открывает встроенный WebView2: часто проверка снимается
сама, иначе в строке сайта появляется «Пройти проверку Modland». Окно с сайтом
открывается для человека; программа капчу не решает и не обходит. После проверки
сайт опрашивается снова.

Сбой одного сайта не мешает остальным: он помечается в списке сайтов, а повтор можно
запустить отдельно.

## Как программа работает с игрой

- «Выключить» и «Включить» работают как в самой игре: меняется флажок `active`
  в `db.json`. Перед правкой прежний файл сохраняется рядом как `db.json.bmm-bak`.
- Пока игра запущена, моды переключает игровой помощник: программа кладёт в папку
  `mods` небольшой служебный мод `bmm_bridge.zip`, и игра сама применяет изменения
  через своё меню модов. Если помощник не отвечает, изменение применится после
  закрытия игры.
- Версия игры определяется по её файлам и журналу; в панели мода видно, для какой
  версии сделан мод.
- Моды из `repo` (скачанные в самой игре) программа не удаляет и не переупаковывает.

## Обновление программы

При запуске программа может проверить, не вышла ли новая версия (это отключается
в настройках). Описание обновления берётся с GitHub, архив скачивается в папку
обновления, проверяются размер и SHA-256. После скачивания появляется кнопка
«Перезапустить»: новая версия запускается, ждёт выхода прежней и записывается на её
место, прежняя сохраняется для отката. Если новая версия не показала окно, прежняя
восстанавливается и эта версия больше не предлагается.

Последний опубликованный выпуск — **1.0.3**. Раздел **1.0.4** в `CHANGES.md` —
готовящиеся изменения; версии в манифестах пока 1.0.3, поэтому выпуск 1.0.4 ещё
не собран.

## Где данные и как удалить

- `%LOCALAPPDATA%\BeamModManager\`:
  - `settings.json` — настройки;
  - `library.json` — библиотека модов, привязки и проверки;
  - `matches.json` — решения «это один мод / это разные»;
  - `previews\` и `search-previews\` — кэш картинок;
  - `WebView2\` — профиль встроенного браузера;
  - `update\` — скачанное обновление программы;
  - `errors.log` — журнал ошибок;
  - подпапка с хешем пути к выбранной папке модов — `disabled\` и `backups\`:
    выключенные файлы и копии прошлых версий;
  - `work\` — временная работа, например перепаковка архива.
- `%TEMP%\BeamModManager\incoming\` — временная распаковка архивов; очищается сама.
- `bmm_bridge.zip` — служебный мод в папке `mods`; его можно удалить после закрытия
  программы, при следующем запуске он ставится заново.

Удалить программу: удалите её папку, `%LOCALAPPDATA%\BeamModManager` и
`mods\bmm_bridge.zip`. Моды в папке игры не трогаются.

## Принципы

- Моды — ваши файлы: программа не прячет их и не меняет формат без вашего действия.
- Платные моды показываются, но не скачиваются: метка «Платный» и ссылка на автора.
- Не обходим платные стены, капчи, таймеры и рекламу. Проверку «вы человек?» проходит
  человек.
- Сайтам — вежливо: один запрос за раз на сайт, паузы, кэш, условные запросы,
  пауза после серии сбоев.
- Сбой одного сайта не ломает остальные.

## Для тех, кто хочет собрать сам

**Стек:** Rust 1.95+ (edition 2024, MSVC x64), Tauri 2.12, SvelteKit 3.1, Svelte 5.57,
Vite 8.3, TypeScript 6.0, Tailwind CSS 4.3, bits-ui и Phosphor. Node.js 24.

```
crates/
  bmm-domain/      библиотека, настройки, совпадения, версии, пути
  bmm-game/        db.json, папки игры, версия, игровой помощник
  bmm-packs/       архивы, распаковка, установка, копии, превью
  bmm-sources/     HTTP-клиент, парсеры сайтов и поиск
  bmm-checks/      планировщик, координатор и проверка обновлений
  bmm-app-release/ проверка и установка обновлений самой программы
src-tauri/         окно Tauri, IPC-команды, состояние приложения
src/               SvelteKit 3: маршруты, компоненты, IPC и оформление
fixtures/          сохранённые страницы сайтов и данные игры для тестов
legacy/            старый C#/WPF, в новой сборке не участвует
```

Сборка и проверки:

```bash
npm ci
npm run check
npm test
npm run build
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
npm run tauri dev
```

Подробнее про CI, версии и выпуск — в [docs/BUILD.md](docs/BUILD.md). Актуальное
состояние — в [docs/STATUS.md](docs/STATUS.md), движение интерфейса — в
[docs/DESIGN_MOTION_WEB.md](docs/DESIGN_MOTION_WEB.md). Остальные документы в `docs/`
помечены как исторические.
